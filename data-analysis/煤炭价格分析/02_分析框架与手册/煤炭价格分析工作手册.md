## 一、工作流信息架构
三栏 + 双箭头 + 底部双护栏：

**① 原料输入**
- 现货/指数价格：秦港 Q5500、BSPI、CCTD、CECI
- 供需/库存：产量、进口、电厂/港口库存
- 政策 / 外部变量：长协区间、安监限产、国际煤价、**国际事件(地缘/政策冲击)**、美元兑人民币汇率(USD/CNY)、海运费
- 用户口述：电厂煤耗、热电联产季节性、采购口径
- 📚 RAG 实时市场数据（WebSearch 抓日度报价/周报/快讯/天气）

**② AI 引擎思维链**
- 接入清洗 → 暂存 → 生成待补清单
- 数据治理：口径铁律、时间戳、不编、跨口径禁 SUM、重复识别、单位统一
- 因子拆解/平衡表：供/需/运/外 四维 + `价格 = f(供给 − 需求 − 库存变动)`
- 情景推演（乐观/中性/悲观）+ 燃料成本测算（煤价 × 煤耗 → 度电成本）

**③ 产出结论**
- 价格池周报 / 待补清单 / 平衡表缺口 / 因子归因 / 月度区间 / 采购清单 → 汇聚成下一步行动

**底部双护栏**
- 红线：口径铁律 / 不编造 / 平衡表可追溯 / 不荐具体交易 / 模式切换
- 保险栓：数据时间戳 / 重复检测（权威源优先）/ 过程可追溯（度电成本 = 煤价 × 煤耗）/ 置信度评级

- 国产：长协 570–770 + 现货（秦港 860–880）

## 五、运输价格（国内铁路 / 公路货车 / 沿海水运 vs 国外海运）
煤炭物流成本由「坑口→集运→港→厂」多段构成：国内以铁路为主干、公路（货车）为短倒/末端、沿海水运为北煤南运补充；国外以国际干散货海运为主。三类国内方式定价机制不同（铁路刚性、公路弹性、沿海居中），需分开跟踪、不能混为一价。

| 运输方式 | 载体 / 路线 | 主要费用 | 定价机制 | 跟踪指标 | 对煤价传导 |
|---|---|---|---|---|---|
| 铁路（主干） | 大秦/朔黄/浩吉线：三西→北方港；蒙东/东北线→电厂 | 铁路运费（国铁运价号，政策定价） | 发改委调控、刚性较强、年度基准+浮动 | 铁路运价政策、大同/神木至港运费 | 进"坑口→港"成本，慢变量 |
| 公路货车（短倒/末端） | 矿区→铁路站台、港口→周边电厂 | 汽运费（按吨公里议价） | 市场化，随柴油价/运力/环保限行波动大 | 区域汽运费、柴油价格、治超政策 | 进"末端到厂"成本，快变量、弹性大 |
| 沿海水运（北煤南运） | 秦皇岛/黄骅→长三角/珠三角港 | 沿海煤炭运价 | 随市场供需、运力波动（中变量） | 煤炭沿海运价指数、运力周转 | 进"港→南方厂"成本，中变量 |
| 国外海运（进口） | 印尼/澳→中国沿海港 | 海运费 + 保险 | FOB + 海运费随国际航运市场 | BDI、Cape运价、纽卡斯尔→中国航线运费、美元兑人民币汇率(USD/CNY) | 进"到岸完税价"，快变量、决定进口性价比 |

> 关键差异：铁路=刚性慢变量，公路货车=弹性快变量，沿海水运=中变量，国外海运=快变量。2026年8月"国际煤价回落 + 海运费波动"使进口性价比回升、进口量环比 +20.02%，反压国内价（利好电厂）。做燃料成本测算时，坑口煤需叠加铁路+公路两段、港口煤需叠加水运/公路末端，方能还原到厂完全成本。

**坑口 → 港 → 厂 物流成本拆解（结构示意）**

```
坑口价 ──[公路货车短倒 · +汽运费·弹性]──> 铁路站台
   ──[铁路主干(大秦/朔黄/浩吉) · +铁路运费·刚性]──> 北方港 ──[港杂费]──> 集运枢纽
                                                                           │
                                    ┌──────────────────────────────────────┤
                              [沿海水运 · +沿海运价·中变量]          [公路末端 · +汽运费·弹性]
                                    ↓                                    ↓
                              南方电厂                              周边电厂
                                    └────────────> 厂到岸完全成本 <────────────┘
```

> 说明：各环节具体运价（元/吨·公里）以国铁运价号 / 区域汽运市场 / 沿海煤炭运价指数实时数据为准；本图仅展示费用构成结构，不列金额、不作估算。

## 七、天气/季节性（一年双峰）
天气穿透 供/需/运 三层的"放大器"。

| 天气事件 | 维度 | 煤价方向 | 作用机制 |
|---|---|---|---|
| 东北/北方供暖季 | 需 | ↑偏多 | 集中供暖→火电负荷↑→日耗↑ |
| 夏季高温制冷(迎峰度夏) | 需 | ↑偏多 | 空调负荷→用电峰值→火电兜底 |
| 寒潮/极寒 | 需+运 | ↑脉冲 | 负荷骤增+运输受阻 |
| 连续阴雨/静稳无风 | 需 | ↑脉冲 | 风光出力骤降、负荷不减→火电顶峰补缺（纯"新能源缺口"触发，无低温驱动） |
| 汛期强降雨 | 供+运 | 中性/↓ | 产区生产/发运受限，但水电挤出 |
| 台风/大风 | 运 | ↑脉冲 | 港口封航、航运受限 |

**典型案例 A：东北供暖对煤炭价格的影响因素**
- 供暖期长、基数大，东北自产(黑吉+蒙东)仍难完全覆盖，需从山西、蒙西外购
- 需求脉冲推价：冬储 + 迎峰度冬
- 极寒放大波动
- 与夏季对称，构成"一年两峰"双顶结构

**典型案例 B：迎峰度夏对煤炭价格的影响因素**
- 制冷负荷脉冲：2026/8/7 用电负荷 15.57 亿千瓦创年内峰值
- 火电日耗拉升→库存去化、补库集中→现货上行
- 对冲项：汛期水电/新能源挤出，故夏峰短而尖、弱于冬峰
- 日内结构：白天光伏大发压低火电出力，傍晚光伏退出恰逢空调晚高峰→火电晚峰陡增（"鸭子曲线"），日内调峰压力大于日均压力
- 2026实证：秦港 Q5500 825→880（月内+55），下旬出伏后收窄（快上快落）

## 八、因子拆解与平衡表
| 维度 | 关键变量 |
|---|---|
| 供 | 国内产量(晋陕蒙)、进口煤到岸、安监/环保限产、产能核增 |
| 需 | 火电负荷(气温/用电高峰)、**新能源(风光)电量挤出**、水电替代、钢铁水泥(焦煤侧) |
| 运 | 大秦线/朔黄线运价、公路汽运、港口吞吐、北港库存 |
| 外 | 国际天然气/油价、澳煤政策、美元兑人民币汇率(USD/CNY)、海运费 |

> 核心公式：**价格 = f(供给 − 需求 − 库存变动)**。把四类变量填进一张平衡表，判断价格在区间哪一侧。

## 九、新能源替代对电煤需求的影响（需求侧结构性因子）

> 新能源不是"天气的附属项"，而是**需求侧的独立结构性变量**。三条链同时作用：两条压低中枢、一条放大短期波动——后者反直觉，最容易被漏掉。
> **口径铁律：分析需求一律看"发电量"、不看"装机"**——风光利用小时远低于煤电，装机占比 ≠ 电量占比。

### 三条传导链

```
新能源装机高增（风光合计 19.51 亿千瓦 · 占总装机 48.3%）
        ├─→ ① 电量挤出  → 煤价中枢下移       （长期利空 · 趋势性）
        ├─→ ② 角色转换  → 总量降 · 波动放大   （中期利空 · 结构性）
        └─→ ③ 出力间歇  → 现货脉冲上涨       （短期利多 · 事件性）
```

| 传导链 | 机理 | 煤价方向 | 时间尺度 |
|---|---|---|---|
| **① 电量挤出** | 可再生能源（风光为主）发电增量直接满足大部分新增用电，火电发电量增速系统性低于用电增速，电煤需求总盘子被压缩 | ↓ 压低中枢 | 长期 · 趋势性 |
| **② 角色转换** | 火电由主体电源转向调节/兜底：**电量被挤出，但顶峰依赖上升** → 需求"总量降、波动增"，不再是平滑曲线，而随风光出力缺口脉冲 | ↓ 中枢 / ↑ 波动 | 中期 · 结构性 |
| **③ 出力间歇** | 无风/少光/连续阴雨 + 用电高峰 → 风光出力骤降，火电顶峰补缺 → 日耗短时激增、库存加速去化 | ↑ 脉冲 | 短期 · 事件性 |

### 2026 年上半年实况（国家能源局 2026-07-30 新闻发布会）

| 指标 | 数值 | 对电煤需求的含义 |
|---|---|---|
| 风光合计装机 | 19.51 亿千瓦（占总装机 48.3%） | 光伏装机已与燃煤发电装机（12.75 亿千瓦）**基本持平** |
| 可再生能源装机 | 24.55 亿千瓦（占总装机 60.7%） | 非化石装机已过六成，煤电装机份额持续被稀释 |
| 风光发电量 | 1.25 万亿千瓦时（占全社会用电 24.6%） | 全国每 4 度电约 1 度来自风光；**电量占比远低于装机占比** |
| 可再生能源发电增量 | 1598 亿千瓦时，覆盖用电增量 **61.9%** | 用电增量六成以上被新能源吃掉 → 电煤需求增速系统性低于用电增速 |
| 煤电发电量占比 | 49.7%（**首次跌破 50%**） | 煤电由"电量主体"退居调节/兜底，标志性拐点 |
| 风光利用率 | 风电 90.9% / 光伏 91.4% | 仍有约 9% 弃风弃光，消纳受限时挤出打折、火电仍须顶上 |

> 口径提醒：装机占比 48.3% ≠ 电量占比 24.6%。**填平衡表一律用发电量口径，禁用装机口径替代**，否则会严重高估替代量。

### 对冲项与边界（避免只算利空）

| 要点 | 说明 |
|---|---|
| **装机 ≠ 电量** | 风光装机占比 48.3%，发电量占比仅 24.6%。挤出须按发电量折算。 |
| **消纳率约束** | 风电利用率 90.9%、光伏 91.4%，仍有约 9% 弃电。外送受限或调峰不足时"发得出、送不出/用不掉"，火电仍须顶上，挤出打折。 |
| **煤电不退出** | 政策定位转向**基础保障性 + 系统调节性电源**（兜底保供、应急备用、灵活调峰）。极端时段顶峰仍依赖煤电，脉冲行情不会消失。 |
| **挤出仍将增强** | 《可再生能源发展"十五五"规划》目标：2030 年风光总装机 28 亿千瓦以上、装机占比超 50%、年发电量 4 万亿千瓦时以上、**发电量占比达 30%**。 |
| **储能/抽蓄对冲** | 削峰填谷既降低火电顶峰需求，也提升新能源消纳从而加大电量挤出，方向均**压制煤价**，但会削弱链③的脉冲幅度。 |

### 观察指标（月度跟踪，回写平衡表）

| 指标 | 怎么看 | 数据源 |
|---|---|---|
| **增量覆盖比**（最关键） | 新能源发电增量 ÷ 全社会用电量增量。**>50% 即过半新增用电由新能源满足**，火电增量被挤压 | 国家能源局月度发布会 / 中电联 |
| 火电发电量及占比 | 占比持续下行 → 中枢压制；某月反弹多为水电枯期或极端天气（链③） | 国家统计局 / 中电联月度快报 |
| 火电利用小时 | 下行=电量被挤；需同步看顶峰时段出力，区分"电量"与"容量" | 中电联《电力行业年度发展报告》 |
| 风光发电量 / 弃风弃光率 | 利用率下降=消纳受限，挤出打折、火电补位 | 全国新能源消纳监测预警中心 |
| 极端时段风光出力 | 寒潮无风、连续阴雨时段的风光出力与火电顶峰日耗，脉冲行情的前置信号 | 省级电力调度 / 气象数据 |

> 落地方式：按月填入第七节"天气观测模板"同级的**新能源跟踪行**，回写第八节平衡表需求侧，与供/运/外三类变量一并参与区间研判。

## 十、落地 6 步法
1. 定口径：动力煤 5500、现货+长协双线
2. 建周度表：价格 + 库存 + 进口 三项滚动
3. 做平衡表：产量+进口 − 消费 − 库存变动 → 看缺口
4. 设情景：政策/天气/进口扰动 各给 乐观·中性·悲观
5. 算成本：煤价 × 供电煤耗 → 度电燃料成本
6. 出结论：下月价格区间 + 采购建议
