# 海运价格分析 · 论文辅助 / 理论依据

> 目的：为「海运价格分析」提供可验证的学术与方法论支撑（指数体系、运价形成机制、事件冲击建模）。仅列真实存在的指数 / 机构 / 方法，附可查证来源。
> 整理日期：2026-09-07 ｜ 方式：新增独立文档，不改任何已有文件。

---

## 一、核心理论框架

- **运价指数体系（事实层数据源）**：
  - **SCFI** 上海出口集装箱运价指数（上海航运交易所发布，反映中国出口集装箱即期市场；新版 2009-10-16 发布，基期 **2009-10-16 = 1000 点**）
  - **SCFIS** 上海出口集装箱结算运价指数（同所，结算价口径；2020-11-02 正式发布，基期 **2020-06-01 = 1000 点**）
  - **BDI** 波罗的海干散货运价指数（Baltic Exchange 发布，干散货全球基准）
  - **NCFI** 宁波出口集装箱运价指数、**PDCI** 内贸集装箱运价指数
- **运价形成机制**：班轮运价由运力供给（运力 / 闲置 / 减速航行）、货量需求（贸易量 / 旺季）、成本（燃油 / 运河 / 保险）、合约结构（长协 vs 即期）共同决定；干散货更贴近即期供需。
- **事件冲击建模**：地缘 / 运河中断（红海绕行 2023.12 起）吸收全球约 **5%–10%** 有效运力，航程 +3000–3500 海里、+10–14 天，推高即期运价并抬高「运价地板」。
- **计量方法**：协整 / VAR、事件研究法（event study）、情景分析用于归因与推演。

## 四、本项目落点（与本分析对应）

- 「指数体系」应直接对接 **SCFI / BDI 官方口径**，避免自造指数。
- 「因子拆解」按 **供给 / 需求 / 成本 / 事件** 四维度，与事件研究法对应。
- 红海绕行作为典型「事件冲击」案例用于情景推演：若复航，行业测算释放 ~6% 有效运力、运价在 3 周内回落 15%–25%（Alphaliner 统计）。
