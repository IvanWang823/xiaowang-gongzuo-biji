## 0. 一句话定义：海运价格到底是什么

海运价格 = **承运人把 1 个 TEU（20 尺标准箱）从起运港运到目的港，向货主收取的即期/合约运费**，单位通常：

- **USD / TEU**（20 尺箱）或 **USD / FEU**（40 尺箱）
- 指数类则无量纲（以某基期为 1000 或 1000 点）

关键认知：**运价 ≠ 船公司收入**。一笔海运总费用 = **基本运费 + 核心附加费 + 港口操作类 + 特定附加费** 四类（详见 §2.2）。看"裸运价"和看"全包价"差距很大，核价/对账必须按四类逐项拆（见 §2.4 审单四大关键点）。

## 1. 先看"看什么"——运价指数体系（别盯错指标）

不同指数口径、频率、覆盖范围都不一样，混用会得出相反结论。

| 指数 | 发布方 | 频率 | 口径 | 代表意义 |
|---|---|---|---|---|
| **SCFI** 上海出口集装箱运价指数 | 上海航运交易所 | 每周五 | 即期（Spot） | 中国出口即期运价风向标，最常用 |
| **CCFI** 中国出口集装箱运价指数 | 上海航运交易所 | 每周五 | 即期+合约综合 | 综合运价水平，波动比 SCFI 平滑 |
| **NCFI** 宁波出口集装箱运价指数 | 宁波航运交易所 | 每周 | 即期 | 华东另一出口锚 |
| **WCI** World Container Index | Drewry | 每周四 | 即期，8 条主干航线 | 全球跨航线即期基准 |
| **FBX** Freightos Baltic Index | Freightos+Baltic | **每日** | 即期 | 高频，适合盯短期异动 |
| **BDI** 波罗的海干散货指数 | 波罗的海交易所 | 每日 | 干散货（铁矿/煤炭/粮食） | **非集装箱**，看大宗商品海运成本 |
| **SCFI 欧线期货** | 上期所(INE) | 交易时段 | 期货 | 可对冲/投机的定价 |

**选哪个？**
- 做**趋势/月度复盘** → SCFI + CCFI
- 做**日度异动监控** → FBX / WCI
- 看**大宗商品（煤炭/铁矿）海运** → BDI（和你本职电力/煤炭成本相关）
- 想**对冲或量化** → SCFI 欧线期货

> 注意：SCFI/CCFI 是**上海航运交易所官方发布**，权威但只有周频；FBX 是商业指数，日频但含平台成交偏差。交叉验证时优先信官方周频。

## 2. 核心影响因素拆解（分析的主轴）

运价本质是**供需定价**，但被成本与事件剧烈扰动。建议按"三层"拆：

### 2.1 供需层（决定方向）
| 维度 | 看什么 | 数据线索 |
|---|---|---|
| **运力供给** | 全球集装箱船队运力（万 TEU）、新船交付、闲置/拆解率、航速（减速=隐性减运力） | Clarksons 船队报告、Alphaliner |
| **货量需求** | 中国出口金额/集装箱吞吐量、欧美进口订单（PMI 新出口订单）、零售商库存 | 海关月报、集装箱港口吞吐量 |
| **舱位利用率** | 船舶平均舱位利用率（85–90% 维稳，>95% 陡增） | 船公司/研究机构周报 |

**核心规律**：运价对舱位利用率极敏感——利用率每越过 90% 临界点，边际涨价弹性骤增。这是"小缺口大波动"的根源。

> **运价弹性经验值（行业硬锚点，供情景测算设系数）**
> - 舱位利用率 **85%–90%**：运价维稳，供需基本平衡
> - 突破 **95%**：呈**非线性陡增**——需求每涨 **1%**，运价往往涨 **5%–10%**（欧线/美线经验法则）
> - 跌破 **85%**：运力过剩，运价易踩踏式下跌
> 用法：做 §4.3 三情景时，把利用率区间映射到上述弹性，而非线性外推。

### 2.2 成本层（决定地板）——按你的四类费用结构拆

一笔海运总价 = **① 基本运费 + ② 核心附加费 + ③ 港口操作类 + ④ 特定附加费**。逐项拆，避免只盯裸运价。

**① 基本运费（Basic Freight）— 运价的"底"**
- 按箱型（TEU/FEU）或计费标准（W/M 择大、FAK、等级运价）计收的基础运费
- 盯：SCFI 即期底价、合约 FAK 价

**② 核心附加费（随运价周期性波动，必收项）**
| 代码 | 名称 | 触发/挂钩 |
|---|---|---|
| **BAF** | 燃油附加费 Bunker Adjustment Factor | 挂钩 VLSFO 低硫油价（IMO 2020 后最大变动成本） |
| **CAF** | 货币调整附加费 Currency Adjustment Factor | 挂钩结算汇率波动 |
| **PSS** | 旺季附加费 Peak Season Surcharge | Q3 圣诞补货 / 春节前抢出口 |
| **GRI** | 综合费率上涨 General Rate Increase | 船司月度"宣涨" |
| **CIC** | 集装箱不平衡费 Container Imbalance Charge | 空箱调运缺口（缺箱时涨） |

**③ 港口操作类（Port / Local，起运港+目的港两端）**
- **THC** 码头操作费（OTHC 起运 / DTHC 目的）
- **DOC** 文件费、**Seal** 封志费
- **安检/申报费**：AMS（美线）、ENS（欧线）、AFR（俄线）等舱单申报
- 港杂费、封条、港建费

**④ 特定附加费（Event-driven，运价尖峰的主要来源）**
- **EU ETS 欧盟碳税附加费**（2024 起航运业纳入欧盟碳交易，2026 全面 100% 征缴 → 欧线刚性成本，随碳价波动）
- **红海/苏伊士绕行附加费**（2023 末起，绕行好望角 → 运距 +30%）
- **巴拿马运河附加费**（干旱限行，影响美东）
- **Congestion 港口拥堵附加费**（塞港=船效下降=等效运力减少）
- **War Risk 战争险附加费**（地缘高风险航线）
- **Winter 冰冻/极地附加费**（季节性）

> 盯盘要点：① 看底价趋势；② BAF/CAF 跟油价汇率走；④ 特定附加费是事件冲击的"放大器"，红海类冲击缓和即回落。

### 2.3 事件/政策层（制造尖峰）
- **红海危机**（2023 末起，胡塞武装袭击，船舶绕行好望角）→ 亚欧航线运距 +30%、运力吸收、运价暴涨
- **地缘/制裁**：针对性航线中断
- **罢工**：美西港口工会（ILWU）、德英港口罢工
- **政策**：美国关税预期（抢出口）、中国出口退税调整
- **疫情类黑天鹅**：港口停摆、需求骤变

> 分析方法：事件冲击通常先在 **SCFI 即期** 体现（1–2 周），再向合约价传导（季度谈约）。

### 2.4 审单四大关键点（核价 / 对账必查）

拿到运费报价单或账单后，按这四点逐条过，防止"低价引流、附加费找补"和重复计费：

| # | 关键点 | 查什么 / 防什么 |
|---|---|---|
| **1** | **计费标准核对** | 确认按 W（重量吨）/ M（体积吨）/ W·M 择大 / FAK 计收；整箱 FCL 还是拼箱 LCL；避免错算箱型导致底价虚高 |
| **2** | **附加费完整 & 防重复** | 逐项比对 §2.2 四类清单：核心附加费是否齐全、港口操作类与特定附加费有无**同一费用收两次**（如 THC 与 local charge 重叠） |
| **3** | **币种 / 汇率 / CAF** | 确认报价币种、结算汇率基准日、CAF 是否已含；避免汇率波动吃掉利润或重复计货币调整 |
| **4** | **约价适用 & 免费箱使期** | 合约价（约价）是否适用于本票；免费用箱/堆存天数（Demurrage & Detention free days）、超期费率；滞期费是否异常 |

> 说明：上表四点为本框架推荐的通用审单清单。若你那边"四大关键点"有固定口径，告诉我具体四条，我直接替换。

### 2.5 合约价（长约）vs 即期价（Spot）— 分析权重

| 维度 | 即期价 Spot | 合约价（长约/BCA） |
|---|---|---|
| 代表 | SCFI、FBX 即期 | 年度合约、指数挂钩长约 |
| 决定什么 | **边际波动**（当下供需+事件冲击） | **船司年度利润底线 / 大直客成本锚** |
| 频率/敏感 | 周频~日频，极敏感 | 季/年谈定，刚性 |
| 谁用 | 临时订舱、短线决策 | 电力进口煤、大型出口商等年度预算 |

**分析用法**：
- 判断"当下该不该订/该不该买" → 盯**即期**
- 判断"全年成本预算/船司盈利" → 盯**长约**
- 即期与长约的**价差（贴水/升水）**本身是信号：即期暴涨时，长约货显性价比；即期崩时，长约货反成负担
- 你的场景：进口煤海运费多用长约或指数挂钩，拆到岸成本时注意用对应口径，别拿即期硬套长约票

### 2.6 与本职联动：BDI → 煤炭到岸价（打通散货逻辑）

散货（煤炭/铁矿）走 BDI 体系，与集装箱是两套逻辑，但服务于你本职成本测算。打通公式：

```
煤炭到岸价（CIF） = FOB 离岸价 + 海运费 + 港杂/保险
海运费（散货）     = BDI 对应分船型运费率 × 吨海里
                    - 澳煤/Q5500 高卡 → 海岬型 BCI
                    - 印尼/南美中卡 → 巴拿马型 BPI
```

**应用**：用《2026 上半年动力煤价格复盘》中"澳洲 Q5500 到岸约 965 元/吨"反拆——
- FOB 离岸价占多少
- 海运费（BDI 走势 + VLSFO 燃油即 BAF）占多少
- 附加费/港杂占多少
→ 精确判断电厂**买内贸还是买进口**的临界点。

> 注意：§2.1–§2.5 主体是集装箱；本 §2.6 仅把散货 BDI 接到你的煤炭成本，两套口径勿混用。

## 4. 怎么分析（方法论）

### 4.1 趋势与周期
- **同比（YoY）**：剔除季节，看周期位置（现在是高位还是低位）
- **环比（WoW）**：看边际方向，周频数据重点看环比
- **分位数**：当前运价处于过去 N 年历史分位的第几%（高位警惕回落，低位看拐点）
- **季节性**：春节前 1–2 月（抢出口）、Q3（欧美圣诞补货）→ 传统旺季，叠加 PSS

### 4.2 相关性/归因
- 运价 vs 油价（弱相关，成本非主因）
- 运价 vs 中国出口金额（强相关，需求驱动）
- 运价 vs 舱位利用率（最强相关）
- 红海绕行后：运价 vs 有效运力（绕行吸收的运力）

方法：用 Python（pandas）做相关系数矩阵 + 滚动相关，找出当阶段主驱动。

### 4.3 情景与预测
- **基准/乐观/悲观**三情景：给定运力增速、货量增速、事件是否缓和
- 运价弹性测算：舱位利用率每变动 X%，运价变动 Y%
- 周频更新，月频复盘

### 4.4 可视化看板（建议）
1. 各航线 SCFI 走势（多线折线，按年着色）
2. 运价历史分位热力图（航线 × 时间）
3. 运价 vs 油价 / 出口金额 双轴图
4. 事件标记时间轴（红海、罢工、关税）

## 5. 标准实操流程（从数据到结论）

```
1. 定目标       → 看趋势？监控异动？测算成本？选对应指数
2. 拉数据       → SCFI 周频历史 + FBX 日频 + 出口/油价辅助
3. 清洗         → 统一币种/单位，补齐缺失周，标注事件日
4. 描述         → 同比/环比/分位，定位当前周期位置
5. 归因         → 相关性分析，识别当阶段主驱动（需求?运力?事件?）
6. 情景         → 三情景定价，给出区间而非单点
7. 出图/出报告  → 看板 + 一段话结论
```

### 5.0 数据日期/周期登记模板（V1.2 强制项，喂数前必填）

> 任何喂入 AI/分析师的原料，必须先登记数据周期，再做下游计算。**禁跨期混算**（今日 SCFI + 上月出口量 = 假精确）。

| 原料类型 | 周期登记示例 | 抓取源周期 | Python 喂数要求 |
|---|---|---|---|
| **运价指数** | `2026W01 ~ 2026W35`（周频）/ `2026-01-01 ~ 2026-08-31`（日频） | SCFI 每周五更新；FBX 日频 | 索引对齐到周结束日或日 |
| **供需/运力** | `2026 月度`（海关）/ `2026W01~W35`（Alphaliner） | 海关月报；Alphaliner 周报 | 月度取月末、周度取周末对齐 |
| **成本/政策** | `VLSFO 2026-08 月均` / `ETS 碳价 2026-09-05 收盘` | Platts/Bloomberg/ICE 当日 | 燃油用月均、碳价用快照日 |
| **用户口述** | `分析区间 + 即期/长约对应日期`（必须明确） | 人工填写 | 区间两端日期必填 |

**校验规则**（Python 自动化）：
1. 周期区间端点必须闭合（左 ≤ 右）
2. 不同原料若周期不一致，必须**显式标注**（如"周频 + 月度"），禁止无声混合
3. 输出图表 X 轴必须以**最短周期**对齐（周频），其他做阶梯/均值映射

## 6. 常见坑（务必避开）

- ❌ 把 SCFI 即期当船公司真实盈利（漏算附加费、合约占比）
- ❌ 单看 BDI 判断集装箱运价（BDI 是干散货，逻辑不同）
- ❌ **跨期混算**（今日 SCFI + 上月出口量 + 半年前油价 = 假精确）——喂数前必填 §5.0 数据周期登记
- ❌ 用 FBX 日频拐点下长期结论（噪声大，需周频确认）
- ❌ 忽略基期：指数点位跨年不可直接比绝对值，要比涨跌幅/分位
- ❌ 事件驱动暴涨后线性外推（红海类冲击有"缓和即回落"特征）
- ❌ 只核基本运费、漏掉附加费重复计收（同一费在港口操作类与特定附加费里被收两次）→ 见 §2.4 审单四大关键点

## 8. 理论依据 · 学术支撑（对应「论文辅助.md」）

> 本节为框架的方法论底层。可验证的指数、机构、方法来源汇总见同目录 **[论文辅助.md](../_元信息/论文辅助.md)**。

- **指数体系权威口径**：SCFI/CCFI/NCFI 由上海航运交易所发布、BDI 由 Baltic Exchange 发布，是事实层数据源；分析须直接对接官方口径，不自造指数。
- **运价形成机制**：供需（运力/货量/舱位利用率）+ 成本（BAF/CAF/ETS）+ 事件（红海绕行）三重驱动；舱位利用率破 95% 呈非线性陡增（行业经验锚点）。
- **事件冲击建模**：红海绕行（2023.12 起）吸收全球 ~5%–10% 有效运力，复航则释放 ~6% 运力、运价 3 周内回落 15%–25%（Alphaliner 统计）；归因用协整/VAR/事件研究法。
