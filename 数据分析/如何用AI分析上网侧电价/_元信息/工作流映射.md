# AI 分析上网侧电价 · 工作流映射说明

> 本目录按「AI 分析上网侧电价（Agent 工作流版）」架构组织。
> 工作流：**① 喂给 AI 的原料 → ② AI 处理引擎（思维链）→ ③ 产出结论 → ⚡ 综合最优报价策略**；
> 全程遵循底部 ⚠️ 提示词工程红线（System Prompt 写明口径 / 单位 / 字段含义）。

## 一、工作流三阶段（提炼自 ④视频成品/deepseek_html_20260825_698db2.html）

- **① 原料（数据层）**：政策电价文件、市场交易数据、企业结算数据、外部因子 ＋ 📚 向量知识库 RAG
- **② 处理引擎（思维链）**：数据清洗·标准化 ＋ 政策条款提取·解析 →（并行两路）多维对比＋度电利润 / 趋势分析＋敏感性 → 政策影响解读＋预测与决策建议
- **③ 产出结论**：各电源电价对比表图、度电利润、政策影响报告、趋势＋敏感性、预测与决策建议 → 汇聚成 ⚡ 综合最优报价策略（上调/下调 X 厘每千瓦时）
- **红线**：务必在 System Prompt 明确口径（含税/不含税）、单位（元/kWh 或 元/MWh）、字段业务含义，否则数值差一个量级
