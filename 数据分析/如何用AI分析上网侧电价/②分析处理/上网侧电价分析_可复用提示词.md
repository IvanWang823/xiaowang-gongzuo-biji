# 上网侧电价分析 · 可复用提示词

> 复制下方 `代码块` 内的全部内容，作为指令发给 AI 即可复现「抓取 + 可视化 + 成因分析」全流程。
> 适用场景：分析某省某月的上网侧（发电侧）现货电价。换月份 / 换省份时改参数即可。
> 来源：辽宁 2026 年 7 月电价分析会话固化（已吸收全部踩坑与红线）。

```text
# 任务：抓取并分析 [省份] [YYYY年MM月] 上网侧（发电侧）现货电价

## 目标
1. 拿到该省该月每日上网侧电价（日前 + 实时，建议 15 分钟级 96 点）真实数据
2. 生成结构化 Excel 日度表
3. 做可视化：全月热力图 / 典型日曲线 / 负价时段指纹图
4. 分析负电价成因、气象代理相关、日前-实时偏差、储能理论套利空间
5. 所有结论必须基于真实抓取数据，不编造、不读图近似

## 数据源（优先官方真源）
- 先探该省发改委 / 电力交易中心官网是否有「统一结算点电价信息表」类页面
  （多为 Vue SPA，curl 只拿框架页，需用 Playwright 渲染抓 XHR 请求）
- 定位隐藏 JSON 接口（常见 POST，请求体 {"date":"YYYY-MM-DD"}）
  返回字段通常为 日前/实时 各 96 点，单位 元/MWh
- 若官方无接口：尝试北极星电力市场网周报
  ⚠️ 周报图表常在微信 mmbiz 图里，网页端无图 → 无法读点，只能取周度极值做交叉验证
- 交叉验证：用周报极值核对抓取值是否一致

## 分析维度
1. 日度表：日期/星期/日前日均/实时日均/最低/最高/负价点数 + 末行月均（负均价红底高亮）
2. 热力图（天×96 点，红=负价，日前/实时可切换，悬停显精确值）
3. 典型日曲线（31 天均值双线 + 单日下钻 + 负价带阴影，预设最深负价日/最高价日）
4. 负价成因四层：①双谷指纹（午间光伏带 + 夜间风电带）②现货边际出清机理
  ③该省具体成因（风光装机结构、负荷特征）④诚实边界
5. 气象代理（open-meteo 免密钥，多城市平均风速 + 短波辐射）与价格做 Pearson/Spearman 相关
  ⚠️ 辐照整体相关常偏弱——须深挖「白天相关 / 风×光交互 / 分位数 / 典型日轮廓」，
     别只报一个总相关系数就下"弱相关"结论（混杂效应会洗平）
6. 日前-实时偏差复盘（逐日/逐时、两系列相关、频带占比）
7. 储能理论套利（假设：4h 储能、效率 90%、低 4h 充高 4h 放，标注为价格理论上限）

## 交付物（存指定目录）
- Excel 日度表（含 96 点样例 Sheet + 来源说明 Sheet）
- 各 HTML 可视化（纯本地 SVG/合规地图，断网可用；地图必须走合规底图如腾讯地图）
- 汇总 MD 报告（含：数据来源与口径、核心结论、各分析小节、踩坑修正、诚实边界）

## 红线（必须遵守）
- 读不到数据就明说"拿不到"，不编造、不读图估算充数
- 不做价格预测、不给决策建议（用户为发电企业，只看客观数据）
- 仅价格数据时，负价因果只能下"强推断 + 相关"结论，不谎称回归闭环
- 储能套利为理论上限，必须标注假设与免责
- 城市级 / 厂址坐标必须核权威源（WGS84），绝不凭记忆填经纬度
- 地图渲染一律走合规底图，不自行绘制含国界 / 省界的底图
```
