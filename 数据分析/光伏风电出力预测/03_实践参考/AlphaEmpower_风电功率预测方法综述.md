## 一、风电出力物理原理（建模前提）

- **风速主导**：输出功率与风速在一定范围内呈**立方关系** `P = ½·ρ·A·Cp·v³`；低于切入风速 / 高于切出风速时停机保护。
- 其他气象因子：**风向**（偏航、尾流相互作用）、**空气密度**（气温/气压决定）、**湍流强度**、**大气稳定度**——共同决定短时波动与预报难度。
- **功率曲线三区段**：切入 → 额定（线性增长）→ 切出；预测须基于具体机型功率曲线。

> 与 `晴川观象_物理模型工具链参考.md` 呼应：晴川给出光伏/风电的具体物理引擎（pvlib/SAPM/Perez、轮毂高度换算），本文给出风电物理关系的原理表述。

## 二、时间尺度四段（比申威三段更全：多了"长期"）

| 尺度 | 提前期 | 主要服务场景 |
| :--- | :--- | :--- |
| **超短期** | 分钟级 ~ 1–4 h | 实时调度、AGC、旋转备用、调频调峰 |
| **短期** | 数小时 ~ 1–3 天 | 日前/日内市场竞价、经济调度、开机组合 |
| **中期** | 数天 ~ 数周 | 运行规划、检修安排、月度/合约交易参考 |
| **长期** | 月度、年度及更长 | 选址与投资规划、消纳能力评估、年度电量合同 |

> 市场实例（原文）：2022 年某省现货市场，风电场日前高估出力而实际不足，遇实时高电价被迫高价购电，单日全省风电损失约 **372.7 万元**——量化了短期预测偏差的经济代价。

> 与 `申威睿思_功率预测平台方法论参考.md` 第一节交叉：申威分段为超短期 0–4h/短期 0–72h/中期 0–14d；本文补充"长期（月/年）"段，用于规划类决策。

## 三、五类主流模型 · 风电专项对比（补清徕美通用谱系表）

| 类别 | 代表方法 | 优点 | 局限 | 典型适用 |
| :--- | :--- | :--- | :--- | :--- |
| **物理模型** | WRF/ECMWF + CFD + 功率曲线 + 地形 | 依赖历史数据少、新场站可用、可解释 | 依赖初始/环境参数精度、计算重、难秒级更新 | 日前/新场址评估 |
| **统计模型** | ARIMA/SARIMA/卡尔曼/持久性 | 成熟、快、平稳条件好 | 依赖长序列、难捕捉非线性与突变（ramp） | 超短期基线 |
| **机器学习** | SVR / RF / XGBoost / LightGBM | 高维非线性、精度较高、实时快 | 数据量要求、超参复杂、"黑箱" | 短期主力 |
| **深度学习** | LSTM/BiLSTM / CNN / Transformer / GAN | 强非线性、自动提取时空特征 | 数据/算力需求极大、不透明 | 高精度/超短期提升 |
| **混合/集成** | 物理+统计校正、Stacking、CNN-LSTM | 优势互补、精度最高 | 建模/维护复杂 | 当前主流方向 |

关键结论（与清徕美一致但更聚焦风电）：
- 物理+统计**残差校正**是经典混合范式；集成/Stacking 多为竞赛与实际最优方案。
- **超短期**常以统计/轻量 ML 保快速响应；**短期**结合 NWP + ML；**高精度场合**上深度学习/混合。

> 与 `清徕美_算法谱系与技术链方法论.md` 第二节交叉：清徕美是通用谱系表（含光伏/跨场景），本文是风电专项五类对比，二者互补。

## 四、概率预测方法族（补行业标准与精度基准的概率章节）

原文梳理的概率预测手段（确定性预测之外的不确定性量化）：
- **核密度估计（KDE）**
- **分位数回归（QR）**
- **上下边界估计（LUBE）**
- **启发式气象情景生成**

并指出概率预测的**评估体系**比确定性更复杂（可靠性 + 分辨率），是未来研究重点。

> 与 `行业标准与精度基准参考.md` 第五节（概率/区间预测）+ `申威睿思` 第三、四节（P10/P50/P90 + 共形校准 ACI）+ `文献清单 #11 Bazionis 2021` 交叉：本文给出概率方法的具体技术族，Bazionis 2021 是系统综述，申威给出工程落地（分位+校准）。

## 五、典型案例（已入文献清单）

1. **Anholt 海上风电 400 MW（Kim 2024, #10）**：LiDAR（来流风先兆）+ SCADA（机组动态）融合，3 h 超短期深度学习（stacking recurrent），平均误差 **6.8%**、窗口内 **2.11%–10.95%**——可作海上超短期基准参考。
2. **贝叶斯优化 XGBoost（Xiong 2022, #8）**：优于 XGBoost/SVM/KELM/LSTM，**ramp 事件与低风速段**最稳健——可作短期基线模型。

## 六、关键挑战与趋势（可作本项目路线图输入）

1. **不确定性与概率预测**：从点预测走向置信区间/概率分布。
2. **极端天气 Ramp Events**：锋面/雷暴大风导致剧烈波动，需雷达/卫星 + 物理-AI 融合。
3. **空间尺度聚合**：高比例渗透下，区域聚合/多场联合预测平滑单场误差。
4. **少样本冷启动**：迁移学习、元学习、GAN 生成合成数据（见 `文献清单 #12 He 2023`）。
5. **在线/自适应更新**：高频 SCADA/LiDAR/边缘计算驱动的流计算与在线学习。
