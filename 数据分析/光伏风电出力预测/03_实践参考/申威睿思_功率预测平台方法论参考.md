## 一、时间尺度口径（标准区间，填补论文辅助缺口）

文章给出新能源功率预测的行业通用分段（与国内"两个细则"考核口径一致）：

| 尺度 | 区间 | 典型用途 |
| :--- | :--- | :--- |
| 超短期 | **0–4 h** | 实时调度、AGC、滚动修正 |
| 短期 | **0–72 h** | 日前申报、现货交易、检修计划 |
| 中期 | **0–14 d** | 电量计划、合约分解、备用安排 |

> 落点：论文辅助第四节提到"超短期/短期/中期多时间尺度"但**未给标准区间**，本项目分析思路应显式标注上述分段，避免尺度混淆。

## 二、数据质量治理（"数据没洗干净，预测就是空谈"）

### 2.1 接入数据类型（预测喂数入口）
- **SCADA 功率遥测**（实发功率）
- **数值天气预报（NWP）**
- **测风及环境监测**（风速、温度、辐照、组件温度等）
- **关口计量**（上网电量计量）
- **AGC 调度指令**
- **历史文件**（归档数据）

### 2.2 数据标签体系（贯穿全流程）
对每个数据点打标签：**可用 / 缺失 / 异常 / 限电 / 重复**，标签随数据走完整个流程，后续每一步都清楚"拿到的是什么质量的数"。

### 2.3 限电识别技术（关键，接上篇"未计限电"口径坑）
- 通过 **实发功率、可用功率、AGC 限值** 三者关系识别限电时段；
- 识别结果应用于**模型训练**与**考核评价**的数据处理，降低限电对预测判断的污染；
- 支持**人工修正限电时段**并自动回灌系统，持续优化精度。

> 落点：与晴川观象文档"未计入限电、检修、故障"的提醒形成闭环——本文档给出**可操作的限电识别与清洗手段**。本项目的分析思路应在"数据预处理"环节显式写清限电识别逻辑。

## 三、分位预测与区间校准（接"概率预测"章节）

### 3.1 P10 / P50 / P90 分位预测
- 不只给确定性点预测，而是给出**出力区间**：P50 作核心参考，P10–P90 反映不同概率水平下的可能出力范围。
- 例：P10=80 MW、P50=100 MW、P90=120 MW → 核心看 100 MW，区间看 80–120 MW 的不确定带。

### 3.2 共形区间校准（Conformal Prediction）
- 超短期预测进一步采用**共形区间校准技术**对 P10–P90 区间做统计校准；
- **ACI（Adaptive Conformal Inference，自适应共形推断）**在线模式：运行中持续更新，**不改变 P50 点预测**的前提下动态调整区间，适应实际分布漂移。
- 共形预测为成熟统计框架（Vovk 等提出）；ACI 为其在线自适应校准变体，可检索 "Adaptive Conformal Inference, Gibbs & Candès, 2021" 获取原始文献。

> 落点：直接支撑论文辅助"集合预报与概率预测"章节——把"分位数/概率密度输出"落到 P10/P50/P90 的工程表达，并补上**区间校准**这一常被遗漏的环节（否则区间会过宽/过窄而失真）。

## 四、模型自迭代 / MLOps 链路（运营化）

候选模型不直接顶替现役，走标准生命周期：

`训练 → 统一评测 → 影子验证(Shadow) → 生产晋升 → 退化回滚`

- **影子验证**：候选模型在真实数据流中与现役模型并行比较，不参与正式预测、不影响对外结果；
- 评测与治理条件均通过后才按流程进入生产；上线后持续监控，**一旦退化即回滚**；
- 支持**自研 / 第三方算法接入**同一套评测与生产体系，长期沉淀为企业数字资产。

> 落点：提醒本项目"模型选型"不只比离线精度，还要考虑**上线机制、漂移监控与回滚**——否则训练集上好看、生产环境很快钝化。

## 五、监管与交易语境（业务落点）

| 概念 | 含义 | 与预测的关系 |
| :--- | :--- | :--- |
| 两个细则 | 国内并网运行考核与辅助服务考核 | 预测精度直接决定考核罚款/补偿 |
| 省调 E 文件 | 向省级调度上报的标准格式文件 | 预测结果需生成 E 文件并留痕（模型版本+数据快照） |
| 现货交易 | 日前/实时电能量市场 | 区间预测支撑报量与偏差风险控制 |
| 爬坡预警 | 出力陡升陡降预警 | 依赖超短期预测与多站态势 |

## 六、与本项目对应总结

1. **时间尺度**：在论文辅助/分析思路显式标注 0–4h / 0–72h / 0–14d 标准分段。
2. **数据治理**：把"接入数据类型 + 标签体系 + 限电识别"写进数据预处理章节。
3. **概率预测**：用 P10/P50/P90 + 共形校准（ACI）具体化"区间预测"，并强调**区间必须校准**。
4. **模型运营**：补充"影子验证 + 回滚"的上线机制，不只评离线精度。
