# 02_出题与试卷

> AI 辅助「命题」的规范与产出：先有可复用的命题方法论，再按方法论出卷。
> 作者：抖音「小王工作笔记」（ID：163277992）

## 定位

本目录沉淀**自制练习卷 / 模拟卷的命题方法论与样例产出**，与 `01_教程文档/`（AI 应用入门与数据分析实操）互补：
前者研究「怎么用 AI 做分析」，本目录研究「怎么用 AI 出题、并把难度控制在预期档位」。

> ⚠️ 目录内所有文档均为**内部教研自制的练习规范与模拟卷**，不是官方命题标准，也不对标任何一次具体考试；产出的卷子仅用于教学与自测，不能替代官方真题。

## 命名与归类约定

- 方法论放 `01_出题思路/`，实际卷子放 `02_模拟试卷/`；新增考试科目时在 `01_出题思路/` 内按「科目 + 出题思路 + 版本号」命名。
- 版本号写在文件名上（如 `v1.2`、`v0.3.5`），正文头部按版本号正序记录变更摘要，便于追溯每次修订。
- 新增样卷命名为 `样例NN-主题-考试场景.md`，并在正文首行注明「对应的出题思路文档 + 版本」，保证卷子与规范可对齐。
