## 0. 一句话原则与使用边界

### 0.1 一句话原则

**英语卷的难点在“造错项”，数学卷的难点在“答案对”。**

一道英语阅读题出错了，学生顶多争论，卷子还能用；一道数学题答案错了，整套卷的信誉当场归零，而且会被学生截图传播。所以数学命题的第一优先级不是巧思，是**可验证性**：每一道题在交卷前都必须走过验算流水线（§6），过不了的题直接删，不要试图用解析去圆。

### 0.2 三条边界：锁死 / 可调 / 需申报

**结论先说：可以按需个性化，但要看改的是哪一层。** 这份规范交付的是骨架，不是模具。**骨架锁死，血肉可调，偏离留痕。**

| 层级 | 包含什么 | 处理方式 |
|---|---|---|
| **锁死**（改了就废卷） | 答案正确且唯一 | 六道验算工序（§6），过不了就删题，不许用解析圆 |
| | 考纲红线：辽宁不考清单 / 考研超纲定理 / 期末超出教学进度 | 逐条对照，越界即废题 |
| | 题型与分值结构（辽宁 10+10+6、120 分；考研 10+6+6、150 分） | 模拟卷不动；练习册可拆成专题 |
| | 分值分配锚点（课时 / 考纲占比 / 省考纲条目） | 换锚点等于换产品，细目表要重做 |
| | 解答题的评分点 | 没有评分点的计算题不交付（§5.3） |
| **可调**（按需自由改） | 范围侧重：同一考纲内先考哪几章、哪章加码 | 自由 |
| | 难度配比 ±5 个百分点 | 自由，但 A 档不得低于 30% |
| | 题量与时长 | 按比例同改，维持 1 分/分钟量级 |
| | 应用背景（几何 / 物理 / 经济） | 自由 |
| | 要不要配图、脚本出图还是手绘 | 自由；图上数值必须与题设一致 |
| | 详解详略（学生版 / 教师版 / 自学版） | 自由 |
| | 变式题包、错因诊断 | 练习册建议加，试卷可不加 |
| | 交付格式（md / docx / pdf / html） | 自由 |
| **需申报**（能改，但必须写进命题说明） | 偏离 §2.1 参数总表的任何一项 | 注明改了哪项、为什么 |
| | 配比与 §4.2 不一致 | 注明原因（如“本单元课时多，C 档提到 25%”） |
| | 教材版本、考纲版本、对标年份 | 卷首标注 |
| | 已知缺口（未盲测、图未渲染、缺音频等） | 命题说明里单列，不许隐瞒 |

> **为什么要把“可调”写出来**：这份文档前面通篇是“定死”“红线”“硬骨架”的语气，很容易被读成“一个字都不能动”。实际上真正不能动的只有四样——**答案对、不超纲、结构自洽、偏离留痕**。其余的（考哪几章、题量多少、难到什么程度、用什么背景、出成什么格式）本来就该按你的教学进度和班级情况改。

> 反过来，**个性化不等于随便**。凡是偏离本文档默认值的，都在命题说明里写一行“改了什么、为什么改”。半年后你回头看这套卷，唯一能救你的就是这一行。

## 一、先分清两种产品形态：试卷 vs 练习册

这一步不做，后面全是白工。两者的组卷逻辑相反。

| | **限时试卷** | **分层练习册** |
|---|---|---|
| 目的 | 区分 + 诊断 | 补漏 + 形成肌肉记忆 |
| 结构 | 一张卷，难度爬坡，前易后难 | 按**考点**分块，每块内部按**错因**分层 |
| 题量关系 | 题与题**不重复**，考覆盖 | 同考点**必须成组**：标准题 → 变式 → 陷阱题 |
| 答案 | 详解 + 评分点 | 详解 + **错因诊断**（“你错在这一步，说明…”） |
| 时间 | 严格限时 | 不限时，但标“目标用时” |
| 成功标准 | 分数分布合理 | 学生能自己定位薄弱点 |

**用户说“出一套练习”，八成要的是右边。** 但如果他要的是“模拟考”，左边才对。开头先问清楚，不要默认。

> 练习册的核心不是“题多”，是**同一考点给三种问法**：正着问（标准）、反着问（给结论求条件）、挖坑问（把某个必要条件藏在细节里，看学生会不会忽略）。学生做完三连，才算真会。

## 二、三个场景：期末 / 专升本（辽宁）/ 考研

**场景决定一切参数**——范围、题量、分值、难度配比，甚至“什么算超纲”。三者的细目表、验算、评分点这套流水线是共用的，**变的全是参数**。先定场景，再动笔。

### 2.1 参数总表

| 参数 | 期末 | 专升本·辽宁 | 考研 |
|---|---|---|---|
| 满分 | 100 | **120** | 150 |
| 时长 | 120 min | **120 min** | 180 min |
| **每分钟需得分** | 0.83 | **1.00** | 0.83 |
| 题量 | 15–20 | **26**（10+10+6） | 22（10+6+6） |
| 题型 | 选择/填空/计算/证明 | **选择 10×3 + 填空 10×3 + 解答 6×10** | 单选 10×5 + 填空 6×5 + 解答 6 题共 70 |
| 范围 | 本学期教学进度 | **考纲五章**：函数极限连续 / 一元微分 / 一元积分 / 向量与空间解析几何 / 多元微积分 | 数一·二·三 全 |
| 能力上限 | 综合应用 | **应用**（不含证明，不含跨章综合） | 掌握（含证明） |
| A/B/C 配比 | 50 / 35 / 15 | **65 / 35 / 0–5** | 60/30/10（基础）→ 30/45/25（强化） |
| 分值依据 | **课时** | **省考纲条目** | **考纲占比**（数一 56/22/22） |
| 超纲边界 | 本学期讲过的定理 | 省考纲条目 | 当年考试大纲 |
| 学生失分主因 | 算错、时间不够 | **算错、步骤不规范、速度** | 找不到入口、讨论不全 |

> **“每分钟需得分”这一行，是这张表里最容易被忽略、但最能解释学生体感的数字。**
>
> 辽宁 1.00 分/分钟，比期末和考研都高 20%。也就是说：它的知识难度最低，但**时间压力最大**。一张辽宁卷出得好不好，八成取决于计算量控不控得住，而不是题够不够难。

### 2.2 期末卷：唯一按“课时”配分的卷子

**三条硬规则**

1. **分值 ∝ 课时占比**。中值定理那章课时最多，分值不能低于 25%。
2. **不许留空白章**。范围里每一章至少一道题，哪怕只值 5 分。
3. **A 档占 50%**。你是在验收“这学期学会没有”，不是在选拔。

**规格**

- 题量 15–20 题；低于 15 题覆盖不住，高于 20 题 120 分钟做不完。
- **第 1 题必须是送分题**（A 档、3 分钟可做完）。作用是稳住心态、建立节奏。
- 证明题 1–2 道足够；占比超过 20%，平均分立刻塌。

**范围（按同济版教材切）**

- 高数上：函数与极限 / 导数与微分 / 微分中值定理与导数应用 / 不定积分 / 定积分及应用（+ 微分方程，视进度）
- 高数下：多元函数微分学 / 重积分 / 曲线曲面积分 / 无穷级数 / 常微分方程

**常见事故**：把考研题直接搬进期末卷。学生平均分 40，这张卷就作废了——期末的功能是验收，不是筛人。**难度天花板定错，比答案算错更致命**：答案错了能改，天花板错了要重做整卷。

### 2.3 考研卷：唯一按“考纲占比”配分的卷子

**三卷差异（最容易出错的地方）**

| | 数一 | 数二 | 数三 |
|---|---|---|---|
| 高数/线代/概率 | 56 / 22 / 22 | 78 / 22 / 0 | 56 / 22 / 22 |
| 空间解析几何与向量代数 | 考 | 不考 | 不考 |
| 三重积分、曲线曲面积分 | 考 | 不考 | 不考 |
| 无穷级数 | 考 | 不考 | 考 |
| 常微分方程 | 考 | 考 | 考（另含经济应用、差分方程） |

> 上表为常规口径，**具体条目以当年考试大纲为准**。把数二的题混进数一、或反之，都是硬伤——不是难不难的问题，是超纲。
>
> 题型结构注：2023 年起为「单选 10×5=50 + 填空 6×5=30 + 解答 6 题共 70」；2022 年及以前为「8×4=32 + 6×4=24 + 9 题共 94」。**每年都可能微调，落地前按当年大纲核对。**

**命题要点**

- 选择 + 填空共 80 分，占 53%。这部分是“会不会”的分水岭，**概念辨析题比例必须够**（可导 vs 连续、极值 vs 最值、收敛 vs 绝对收敛、线性相关 vs 无关）。全卷概念题低于 15%，这张卷就只测了计算。
- 解答题要留“入口不唯一”的空间（一题多解）。考研给的是关键步骤分，独解题会误伤正确思路。
- 难度锚定用**近 5 年真题**，不用感觉。
- 证明题集中在中值定理、不等式、级数敛散、矩阵可对角化。**每道证明题必须能说清“第一步为什么想到这个构造”**，说不清就是背题型。

### 2.4 专升本·辽宁：唯一“题型板块全固定”的卷子

**依据**：《辽宁省普通高校专升本招生考试数学考试纲要》（以当年发布版本为准；本文按 2026 版）。数学为理科公共课，120 分，与外语（120）、计算机应用基础（100）合计统考 340 分。

**卷面结构（几乎不会变）**

| 题型 | 题量 | 每题分 | 小计 | 单题目标用时 |
|---|---|---|---|---|
| 选择题 | 10 | 3 | 30 | ≤ 2.5 min |
| 填空题 | 10 | 3 | 30 | ≤ 2.5 min |
| 解答题 | 6 | 10 | 60 | ≤ 12 min |
| 合计 | 26 | — | 120 | 120 min |

**考纲五章与能力层次**

| 章 | 内容 | 权重判断 |
|---|---|---|
| 一 | 函数、极限与连续 | 高（解答题常驻） |
| 二 | 一元函数微分学及其应用（洛必达、单调性、极值最值、凹凸拐点） | 高 |
| 三 | 一元函数积分学及其应用（不定积分、定积分、面积与旋转体体积） | 最高（计算量集中） |
| 四 | 向量代数与空间解析几何（向量运算、平面与直线） | 中（客观题为主） |
| 五 | 多元函数微积分（偏导、全微分、无条件极值、二重积分） | 中高 |

考纲的能力层次**只有三档：识记 / 领会 / 应用**。注意——**最高档是“应用”，没有“综合应用”，也没有“证明”**。这不是文字游戏，它直接决定了：跨章综合题和证明题在这个场景里属于超纲。

**不考清单（命题红线，逐条对着考纲核对过）**

- 无穷级数（含幂级数、敛散判别）
- 常微分方程
- 三重积分、曲线积分、曲面积分、场论
- **二重积分的极坐标计算**（考纲只写“直角坐标系下”）
- 条件极值与拉格朗日乘数法（只考无条件极值）
- **中值定理（罗尔/拉格朗日/柯西）及其构造证明题**
- 泰勒 / 麦克劳林公式
- 反常（广义）积分（考纲未列）
- 空间曲面与空间曲线（只有平面与直线）
- 定积分的物理应用（只有面积与旋转体体积）

> 边界提醒：“考纲未列”不等于“绝对不会出现”，但**命题一律按不考处理**。多出一道超纲题，损失的是整套卷的可信度。

**五条命题启示**

1. **六道解答题按板块一一对应**，通常落在：极限 / 导数应用 / 不定积分 / 定积分应用 / 多元偏导或极值 / 二重积分。**不要两道题撞同一板块**，也不要让某章缺席。
2. **计算量是这张卷的命门**。1 分/分钟下，一道 10 分题若算 15 分钟，全卷必然崩。每题必须设“目标用时”，超时就改题，不是改答案。
3. **选择题 3 分/题，只能考概念和“一眼判断”**。让一道 3 分题耗掉 5 分钟，是设计事故，不是难度。
4. **不考证明 → 难度只能从“概念易混”和“算得杂”里造**，不能靠构造辅助函数。把中值定理证明搬进来，既是超纲，也是把难度天花板顶破。
5. **客观题 60 分占一半，单题只值 3 分**——错 4 道 = 12 分 ≈ 一道解答题没了。所以客观题要“稳”，不要“刁”。

### 2.5 同一知识点，三种考法（真正的比较在这里）

光比参数没意义。同一个知识点放进三个场景，**考不考、以什么形态考、占多重的分量**完全不同：

| 知识点 | 期末 | 辽宁专升本 | 考研 |
|---|---|---|---|
| 极限计算（等价无穷小、洛必达） | 必考，计算题起点 | **必考**，解答题第 1 题常驻 | 必考，多作综合题第一步 |
| 中值定理证明 | 考 1 题（若本章已讲） | **不考** | **必考**，压轴常客 |
| 单调性 / 极值 / 最值应用 | 考 | 考（含简单应用） | 考，常与不等式证明合并 |
| 凹凸性与拐点 | 考 | 考（识记层，客观题） | 低频，多在选择 |
| 不定积分（换元 + 分部） | 考 | **必考**，第二类换元限三角与简单根式 | 考 |
| 定积分应用（面积、旋转体） | 考 | **必考**，旋转体体积在识记层 | 考 |
| 反常积分 | 常考（若已讲） | **不考**（考纲未列） | 考 |
| 微分方程 | 视进度 | **不考** | 三卷都考 |
| 空间解析几何（向量、平面直线） | 视进度（高数下） | **考**（客观题为主） | 数一考，数二数三不考 |
| 多元偏导 / 全微分 | 高数下 | 考 | 考 |
| 无条件极值 | 高数下 | **考**（不考条件极值） | 考（含条件极值、拉格朗日乘数法） |
| 二重积分 | 直角 + 极坐标 | **仅直角坐标** | 全考（数一另有三重积分） |
| 无穷级数 | 高数下 | **不考** | 数一、数三考，数二不考 |
| 曲线曲面积分 | 高数下 | **不考** | 数一考 |

**读这张表的方法**：横着看是“一个知识点在三种卷子里的地位差”，竖着看是“一张卷子的能力结构”。三条最有价值的差：

- **中值定理**：考研的生命线、辽宁的红线、期末的可选项。同一道题，在三种卷子里分别是压轴、废题、加分题。
- **二重积分**：辽宁只考直角坐标，意味着**换序**是它的高频考点（因为极坐标这条捷径被封了）。
- **无穷级数与微分方程**：辽宁整章不考，所以它的高数“看起来短”，实际是把 0.83→1.00 的时间压力压在了剩下的五章上。

### 2.6 三句话速记

| 场景 | 一句话本质 | 命题时最该盯的一件事 |
|---|---|---|
| 期末 | 考“这学期学会没有” | 按课时铺开，A 档占一半 |
| 辽宁专升本 | 考“基础题能不能又快又对” | **计算量控制**（1 分/分钟） |
| 考研 | 考“能不能自己想出第一步” | 综合度与证明入口 |

## 三、硬骨架：先画双向细目表，再写题

这是数学命题和专业命题的分水岭。**先有表，后有题**；不是写完题再回头统计覆盖了哪些知识点。

### 3.1 表的形状

行 = 知识点（按教材章节或考纲条目，细到“隐函数求导”这一级），列 = 认知层级。

| 知识点 | 识记 | 理解 | 简单应用 | 综合应用 | 分值 | 题号 |
|---|---|---|---|---|---|---|

- **识记**：定义、定理条件、公式（几乎不单独出题，只做选择题素材）
- **理解**：概念辨析、判敛散、可导/连续关系
- **简单应用**：会算（求导、求积分、求极限）
- **综合应用**：跨知识点、需选方法、需讨论

**口径换算**：辽宁考纲的“识记/领会/应用”三档，对应本表“识记/理解/简单应用+综合应用”。**辽宁卷的“综合应用”列应当是空的**——不是命题偷懒，是考纲不要求。

**判据**：一格都不许空着交卷。若某知识点只有“简单应用”、没有任何“理解”层题，说明这一章只考了手熟，没考懂——而考研和期末的失分点恰恰在理解层。

### 3.2 分值分配的三条规则

1. **分值按场景取锚**（见 §2.1）：期末用课时占比，专升本用省考纲条目占比，考研用考纲占比。这是最容易被跳过、也最容易出事故的一步。
2. **认知层级呈金字塔**：理解层 ≥ 20% 分值，综合层 ≤ 30% 分值。
3. **一个知识点最多两个题号**。第三次出现同一考点，说明你在凑题量，不是在组卷。

### 3.3 示例：一张单元小测的细目表

「一元函数微分学」12 题 / 60 分 / 60 分钟

| 题号 | 知识点 | 层级 | 难度 | 题型 | 分值 | 目标用时 |
|---|---|---|---|---|---|---|
| 1 | 导数定义与可导性 | 理解 | A | 选择 | 3 | 2 min |
| 2 | 极值点与驻点的关系 | 理解 | A | 选择 | 3 | 2 min |
| 3 | 凹凸性与拐点判定 | 理解 | B | 选择 | 3 | 3 min |
| 4 | 无穷小阶的比较 | 理解 | C | 选择 | 3 | 3 min |
| 5 | 复合函数求导 | 简单应用 | A | 填空 | 3 | 2 min |
| 6 | 隐函数求导 | 简单应用 | A | 填空 | 3 | 3 min |
| 7 | 参数方程二阶导 | 简单应用 | B | 填空 | 3 | 4 min |
| 8 | n 阶导数 | 简单应用 | B | 填空 | 3 | 4 min |
| 9 | 含参单调性与极值 | 综合 | B | 计算 | 8 | 9 min |
| 10 | 最优化应用（几何） | 综合 | A | 计算 | 8 | 8 min |
| 11 | 方程根的个数讨论 | 综合 | B | 计算 | 8 | 9 min |
| 12 | 不等式证明（拉格朗日） | 综合 | C | 证明 | 12 | 12 min |

**实测配比**：A 20 分 / B 25 分 / C 15 分 = 33 / 42 / 25，偏难。

**改法（先改表，再改题）**：题 4 的“伪难”换成概念辨析，题 7、题 8 压回 A（都是标准套路），客观题只留题 3 一个 B；计算题保留 9、11 两个 B；题 12 仍是唯一的 C。改完是 **29 / 19 / 12 = 48 / 32 / 20**。

**为什么不是 40 / 45 / 15**：这道 12 分的证明题一个人就占了 20% 的 C 份额。要把 C 压到 15%（9 分），只有两条路——把证明题标成 A/B（自欺欺人），或者拆掉证明题换成三个 3 分小题（可单元测不能没有证明）。所以**目标配比必须和题型的分值粒度对齐**：含 12 分证明题的单元，C 的下限就是 20%。

**由此推出一条原则**：配比不能靠“改标签”凑。把一道 8 分题从 B 标成 A，表好看了，题目一点没变，学生该不会还是不会。要动就动题目本身——换题、拆问、砍步骤，或者改分值。

> 这就是先画表的价值：**偏难是在表上发现的，不是在学生考砸之后发现的。**

## 四、难度：四个旋钮 + 三档

### 4.1 “难”和“繁”必须分开

老师嘴里说“这题难”，实际可能是三种完全不同的东西：

- **抽象**（给的是抽象函数 f，不是具体表达式）
- **技巧**（需要构造辅助函数、换元、放缩）
- **繁**（方法很标准，但要算 8 步）

三者的教学含义完全不同：抽象弱 → 概念不清；技巧弱 → 题型积累不足；繁不过关 → 熟练度和心态问题。**组卷时要把三个轴分别记账**，不能笼统标“难”。

判据：一道题若**方法一眼可见、只是算得长**，它不该进 C 档；C 档留给“方法不明显”的题。

> 辽宁卷尤其要注意：它的“难”几乎全部来自**繁**，而不是抽象或技巧。所以那里的“难度”其实要读作“计算量 + 时间”。

### 4.2 三档的定义（要能被第三方复现）

| 档 | 定义 | 步数 | 目标正确率 | 参考锚 |
|---|---|---|---|---|
| **A 基础** | 单一知识点，套用课上讲过的标准方法 | 2–3 步 | 70–85% | 教材例题 / 课后习题前 1/3 |
| **B 综合** | 2–3 个知识点串联，需自行选择方法 | 4–6 步 | 35–55% | 考研真题中档题 / 期末压轴前一题 |
| **C 拔高** | 需构造、讨论、放缩，或方法不明 | 6 步以上 | 10–25% | 考研真题压轴 / 竞赛初赛 |

**配比（按分值，场景对应见 §2）**

| 场景 | A | B | C |
|---|---|---|---|
| 期末复习卷 | 50% | 35% | 15% |
| 单元小测 | 48% | 32% | 20% |
| 专升本·辽宁 | **65%** | **35%** | **0–5%** |
| 考研·基础阶段 | 60% | 30% | 10% |
| 考研·强化阶段 | 30% | 45% | 25% |

> **单元小测的 C 档为什么是 20%**：一道 12 分的证明题本身就占 20%，压不下去。若该单元不含证明题，可回到 50 / 35 / 15。

> **A 档不能低于 30%**。低于这条线，学生做两题就崩，后面的题全部蒙——这张卷的测量功能已经废了，只剩下打击功能。

### 4.3 四个旋钮

| 旋钮 | 调低 | 调高 |
|---|---|---|
| 抽象层级 | 具体函数 `f(x)=x²eˣ` | 抽象函数 `f(x)` 满足某条件 |
| 技巧层级 | 直接套公式 | 需构造辅助函数 / 换元 / 放缩 |
| 计算量 | 3 步内出结果 | 8 步以上，中间要整理 |
| 交叉度 | 单章内 | 三章交叉（极限 + 微分 + 积分） |

外加一个**设问方式**的开关：求值 → 判断 → 证明 → 存在性讨论，难度依次上升，且这个开关不增加计算量，是“低成本加难度”的首选。

**场景适配**：辽宁只能动“计算量”这一个旋钮（以及“概念易混度”）；考研四个都能动；期末主要动“计算量”和“交叉度”。

## 五、各题型命题细则

### 5.1 选择题：错项必须“像”

数学选择题的通病是三个错项一眼假，学生靠“量纲/符号/大致范围”就能排除。**四个选项必须来自同一条错误路径的不同岔口。**

**错项四来源（每道题至少覆盖三类）**

| 类型 | 做法 | 例（题：求 ∫dx/(x²−1)） |
|---|---|---|
| 典型错解 | 用学生会犯的那一步错 | 漏绝对值：`½ln(x²−1)+C` |
| 条件缺失 | 少一个条件时的“另一个合理答案” | 只给 `½ln((x−1)/(x+1))+C`，不加绝对值也不说明区间 |
| 概念混淆 | 混淆两个相邻概念 | 把 `arctanh` 与 `arccoth` 弄反 |
| 半对 | 前两步对、后一步错 | 系数错成 2 倍，形式完全正确 |

**正确答案不显著最长/最短**，这条和英语一样成立。

**坑**：四个选项里只有一个带 `+C`——学生不看题就知道选它。积分题的所有选项必须**统一带或统一不带**常数项。

> **辽宁专版提醒**：3 分/题，考的是“一眼判断”。选项之间若能靠估算、符号、量级排除，这道题就退化成送分。反过来，如果一道选择需要动笔算 3 步以上，它应该变成填空或解答题。

### 5.2 填空题：只考“结果唯一且短”的

适合：求导、求积分、求极限、求偏导、判敛散、求收敛半径、求某点值。

不适合：需要分类讨论的（学生写不全，判卷也难）、结果形式不唯一的（`ln|x|` 与 `ln x`、`arcsin` 与 `arccos` 互化）。

**规范**：一空一答案，答案形式在卷首统一约定（如“结果保留到小数点后两位”或“用反三角函数表示”）。**约定不写，这题就是废题。**

### 5.3 计算题：评分点比答案值钱

一道 10 分的计算题，标准答案只值 1 分，剩下 9 分是**过程分**。所以命题时必须同时产出：

```
评分点拆解（示例）
1. 写出定义域/收敛区间          1 分
2. 正确的换元或分部            3 分
3. 中间结果正确                3 分
4. 最终结果                    2 分
5. 讨论参数或说明取值范围      1 分
```

**没有评分点的计算题不要交出去**——老师讲评时只能念答案，学生不知道分扣在哪，这道题的训练价值损失一半。

> 辽宁卷的解答题全部是计算题（无证明），60 分全靠这 6 道。评分点粗一档，学生就少拿 2–3 分，这不是小事。

### 5.4 证明题：考的是“第一步从哪来”

证明题的价值全在**入口**。命题时要写清：

- **入口提示**：看到“存在 ξ 使 f′(ξ)=…”，第一反应是罗尔/拉格朗日，还是构造 F(x)？
- **构造动机**：辅助函数为什么长这样（这一步不写，学生只能背题型）
- **可接受的替代证法**：至少列 1 种，否则“标准答案唯一”会误伤正确解法

**坑**：证明题超纲。用泰勒展开证不等式，在没讲泰勒的学期就是废题；用柯西中值定理证，在只讲到拉格朗日的阶段也是废题。**超纲不是难度，是事故。**

> 辽宁卷**不出证明题**（考纲能力上限为“应用”）。这一节对它不适用，但期末和考研适用。

### 5.5 应用题与图形题

- 应用题必须有**明确的物理/几何背景**，且变量含义在题面写清（“设 t 为时间，单位：秒”）。
- 需要配图时，图由脚本生成（matplotlib 矢量图），且**图上标注的数值必须与题设一致**。最常见的事故是图里画 a=2、题里写 a=3。
- 图不是装饰：几何应用题不给图，学生要先自己建模，难度会额外涨一档，这个涨幅要算进旋钮里。

## 六、验算：数学卷唯一的质控线

**这一节是整份文档最重要的部分。** AI 出数学题的最大风险不是“题不好”，是“题错”。而且错误率随步骤数上升，10 步的计算题人工检查一遍的漏检率相当高。

每道题交卷前必须过六道工序，**逐题记录用了哪几道、结果如何**：

| # | 工序 | 做法 | 能抓什么 |
|---|---|---|---|
| 1 | **符号验算** | SymPy 对拍：求导、积分、极限、级数展开、方程求解 | 计算错误、符号错、系数错 |
| 2 | **数值抽查** | 参数取具体值（a=1, n=2），数值积分/数值解比对 | 符号推导正确但边界处理错 |
| 3 | **反向代入** | 解代回原方程/原条件 | 增根、丢解 |
| 4 | **端点与退化** | n=1,2；a=0；区间收缩为点；分母趋零 | 讨论不完备 |
| 5 | **特例检验** | 取使结论显然成立的特例，看是否自洽 | 题设条件不足或多余 |
| 6 | **独立盲做** | 换人（或换模型）从零重做，比对**解法路径**而非只比答案 | 多解、歧义、隐藏条件 |

**判定**：六道里至少过 1、2、6 三道，才能进卷。任何一道报“存疑”，这题删掉或改写，**不许靠解析圆**。

> 数学题和英语题的一个关键差异：英语的“两个答案都说得通”是命题失误；数学的“两个答案都说得通”往往是**题目条件不足**，属于硬错误，没有辩解空间。
>
> 另一个差异：英语可以靠“再读一遍原文”来验，数学不行——**数学必须靠独立路径复算**。同一条思路算两遍，第二遍会复现第一遍的错误。

**讨论完备性专项检查**（高数最高频的失分点，单独列）

- [ ] 绝对值：`∫dx/x = ln|x|+C`，开方、去根号时的正负
- [ ] 区间开闭：连续/可导的前提区间端点
- [ ] 参数分界：含参讨论的临界值是否找全（判别式 =0、分母 =0、首项系数 =0）
- [ ] 收敛域端点：幂级数在 ±R 处单独判
- [ ] 广义积分瑕点：瑕点是否落在积分区间内
- [ ] 隐函数存在条件：F′_y ≠ 0 是否满足

> 组卷时逐条打勾，打不了的条目就是这道题的待验项——不要跳过。

> 辽宁卷不需要“收敛域端点”这一条（不考级数），但**二重积分的积分区域分块**是它的高发区——直角坐标下先 x 后 y 还是先 y 后 x，分界线漏一条，整题崩。

## 七、组卷与排版规则

1. **难度爬坡**：整卷难度单调不降（允许局部起伏，但前 30% 分值必须是 A 档）。
2. **同章不连排**：同一章的题最多连续 2 道，第 3 道必须换章。
3. **计算量总量**：全卷纯计算时间 ≤ 考试时长的 70%，留 30% 给检查。反推：单题用时 A ≤ 4 min、B ≤ 8 min、C ≤ 12 min。
4. **一题一个新技巧**：同一道题里不要塞两个“没见过的招”，那是炫技，不是考试。
5. **数字要好看**：最终结果尽量是整数、简单分数、e、π、ln2 这类。结果丑陋 → 学生怀疑自己 → 验算成本暴涨 → 出错率上升，是连锁反应。
6. **卷面分层**：题目区、答题区、草稿区分离；大题留白 ≥ 答案长度的 2 倍。
7. **答案页独立成文件**，不要在同一个 PDF 里跟在题目后面（学生会翻）。

**辽宁专版替换第 3 条**：全卷按 1 分/分钟倒推，客观题 20 题合计 ≤ 35 分钟，解答题 6 题合计 ≤ 75 分钟，余 10 分钟机动。**任何一道题超出目标用时 30%，直接换题。**

## 八、十个最常见的坑

| # | 坑 | 表现 | 对策 |
|---|---|---|---|
| 1 | **答案错** | 符号、系数、常数项 | §6 六道工序，1/2/6 必过 |
| 2 | **漏解** | 分类讨论只做了一半 | 参数分界点必须穷举并写进解析 |
| 3 | **条件多余** | 题给的条件一个都用不上 | 每条件标注“用在评分点第几步” |
| 4 | **条件不足** | 存在多个正确答案 | 特例检验 + 盲做 |
| 5 | **超纲** | 用了考纲外的定理 | 每个解法标注“依据定理是否在范围内” |
| 6 | **计算量爆炸** | 一题算 20 分钟 | 设“目标用时”，超时改题不改答案 |
| 7 | **套路化** | 10 题全是洛必达 + 等价无穷小 | 细目表强制“理解层 ≥ 20%” |
| 8 | **炫技** | 需要神仙换元，无教学迁移价值 | 技巧题 ≤ 全卷 15% |
| 9 | **原题照搬** | 与教材课后题/真题逐字相同 | 三换：换数字、换设问、换外壳 |
| 10 | **难度天花板错** | 期末按考研难度出 / 辽宁按考研难度出 | §2.1 定死配比，出卷前先看表 |

**关于第 9 条（题源与版权）**：数学题不存在“整篇转载”的问题，但存在“原题照搬”。改编的标准动作是三换——**换数字、换设问、换外壳**（把 `f(x)=x²eˣ` 换成“设 f 满足 f′(x)=(2x+x²)eˣ”）。只换数字不算改编，学生一搜就找到原题，这道题就废了。注意区分场景：**变式练习允许只换数字**（目的是同型重复训练），**模拟卷和测试卷不允许**（目的是真实测量）。

## 十、工作流与时间预算（30 题规模）

| 阶段 | 内容 | 参考耗时 |
|---|---|---|
| 0 | 定场景：期末 / 辽宁专升本 / 考研，再定范围、教材版本、题量、时长 | 0.5 h |
| 1 | 按场景取分值锚，画双向细目表 | 1 h |
| 2 | 按表填题（先 A 后 C，C 档最费时） | 3–5 h |
| 3 | 验算（脚本 + 手算，逐题过工序 1–5） | 1.5 h |
| 4 | 写详解与评分点 | 2 h |
| 5 | 盲做与修订 | 1.5 h |
| 6 | 排版、配图、交叉引用 | 1 h |
| **合计** | | **约 10 h / 套** |

AI 辅助可以把 2、4 压到 1/3，**但第 3、5 阶段一秒钟都省不掉**——这两步正是 AI 最容易骗过自己的地方（它“算”出的答案和它“写”的解析会自洽地错在一起）。

---

## 十一、下一步：需要拍板的事

三个场景的默认值已由 §2 给出，剩下的是选型：

1. **场景**：期末 / 辽宁专升本 / 考研（数几）？——若走辽宁，还要确认报考年份（考纲每年可能微调）。
2. **教材**：同济七版/八版？还是按考纲条目走？（决定知识点颗粒度和超纲判定）
3. **范围**：高数上，还是含下册？（辽宁卷固定为考纲五章，这一项可跳过）
4. **规模**：多少题 / 多少分 / 多少分钟？
5. **形态**：限时套卷 / 分层练习册（含错因诊断与变式）/ 两者都要？
6. **交付格式**：Markdown / Word / PDF？几何图形需不需要配图？

**建议的第一次落地**：不要一上来做整卷。先做**一个单元的 12 题小样**（比如「一元函数微分学」或「不定积分」），走完整条流水线，验证三件事——难度手感准不准、验算流程跑不跑得通、详解的详细程度是否合适。这一步大约 2 小时，比做完一整卷再返工便宜得多。

> 若定辽宁专升本：小样直接按 **10 选择 + 10 填空 + 6 解答**的骨架搭，只填其中一章，其余留空。这样能同时验证“板块配额”和“计算量”两件事。
