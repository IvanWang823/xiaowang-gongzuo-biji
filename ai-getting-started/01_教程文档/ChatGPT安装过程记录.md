# ChatGPT 桌面端（Windows 应用商店版）安装与配置记录

> 记录日期：2026-09-24（昨天）
> 说明：这篇记录一下 ChatGPT 桌面端怎么装的、Key 从哪拿的、最后怎么配的。

## 一、装在哪、Key 从哪拿

- **安装来源**：Windows 应用商店（Microsoft Store）
- **API Key 来源**：OpenAI Platform（platform.openai.com）后台签发的

## 二、大概过程

1. 打开 Windows 应用商店，搜 ChatGPT，把桌面客户端装上。
2. 登录 OpenAI Platform（platform.openai.com），在 API Keys 页面建一个 API Key。
3. 打开 ChatGPT 桌面客户端，在设置里把 API Key 填进去。
4. 启动客户端，发条消息看看能不能正常回复。

## 三、最后用的配置

| 配置项 | 值 | 说明 |
| --- | --- | --- |
| 客户端来源 | Microsoft Store | Windows 应用商店装的 |
| API Key | OpenAI Platform 签发的 Key | 在 platform.openai.com 后台创建的 |

## 四、几个小提醒

1. 用之前记得把 CC Switch 打开，不打开的话 ChatGPT 用不了。
2. API Key 是敏感凭据，好好收着，别明文发出去，也别提交到代码仓库。
3. Key 有额度限制，留意一下用量和计费。
