## 1. 角色与控制权

| 角色 | 职责 |
|---|---|
| AI / 脚本 | A0-A8：准备素材、登录校验、上传、校验、填充、终验、存 `draft_id` |
| bsk / Playwright | 浏览器会话、页面操作、上传、DOM 读取 |
| 守护进程 | 管理 bsk 生命周期，脚本结束不关浏览器 |
| 用户 | B1-B4：预览、润色、保存、人工点发布 |
| 润笔 | 人工润色与内容修改，修改优先级最高 |
| 运维 | 监控、告警、Token 冻结、重扫码、选择器维护 |

### 控制权交接

- 还权方式：点击聊天框橙色「中断」按钮，停止 AI 动作，不关闭浏览器。
- **切勿**执行 `bsk session stop`，该操作会关闭页面并导致草稿丢失。
- 脚本正常结束不关浏览器：bsk 生命周期归守护进程，与 Python 脚本进程无关。
- 正文仅填充一次，话题合并一次性写入，杜绝 `contenteditable` 重复写入 Bug。
- 终验阶段读取真实 DOM 的 `innerText`，不要依赖快照（snapshot）文本，防止框内内容重复。

## 2. 总体流程

### 自动化阶段 A0-A8

| 步骤 | 内容 | 图文特化要求 |
|---|---|---|
| A0 | 准备素材落本地 JSON | 图文副本、图片路径、顺序、封面、标题、正文、话题、@、地点、合集、可见范围、原创声明 |
| A1 | 启动会话 + 登录校验 | 未登录扫码；滑块重试 3 次；短信间隔 ≥60 秒；连续失败冻结转人工；多账号隔离 |
| A2 | 会话稳定与限频基线 | 固定浏览器版本、分辨率、时区、语言；随机延迟；遵守频率限制；不承诺规避平台检测 |
| A3 | 进入创作编辑器 | 仅图文入口；多版本选择器；页面状态判断；失败截图 |
| A4 | 上传素材 | `setInputFiles` 原生；预上传 30 秒超时；分片 5 分钟超时；按 `order` 上传；失败重传最多 2 次 |
| A5 | 上传校验 | 强制图片数量 =9 张；格式 JPG/PNG/WebP；宽高比 3:4；单图 ≤20MB；图片短边 ≥1080px；封面校验；EXIF 信息清理；使用 sha256 做图片去重；检测二维码/水印/联系方式/敏感图片 |
| A6 | 填充元数据 | 逐字打字机延迟：80~250ms（高斯随机）；标点停顿：500~1200ms；标题、正文、话题、@、地点、合集、可见范围、原创声明；正文只填一次 |
| A7 | 发布前终验 | 站内预览 + 大模型初筛：违禁词、外链、联系方式、二维码、话题时效、重复发布、草稿完整性；低风险自动替换，高风险转人工 |
| A8 | 仅存 `draft_id` + 变更日志 | Token 剩余时长小于 30 分钟时发飞书/钉钉告警，不自动续期；超时冻结等人工重扫码；变更日志必须记录修正前后 |

### 人工阶段 B1-B4

| 步骤 | 内容 | 防呆要求 |
|---|---|---|
| B1 | 草稿箱 / 预览链接打开 | 顶部高亮提示条显示自动修正；展示修正前后对比；可回滚 |
| B2 | 润色修改 → 点保存 | 触发反读回调 A8 回写本地；人工修改优先级最高 |
| B3 | 人工点「确认发布」 | 二次确认；发布按钮永留人工；AI 不得代点 |
| B4 | 完成 | 回写 `note_id`、URL、发布时间、截图、状态、通知 |

## 3. 图文素材规范

### 3.1 图片

- 数量：强制 =9 张满配；不足或超出转人工。
- 格式：JPG / PNG / WebP。
- 宽高比：3:4。
- 单图大小：≤20MB。
- 短边：≥1080px。
- 封面：必须指定 1 张封面图。
- 清理：上传前清理 EXIF，避免隐私信息。
- 去重：按 sha256 检测重复图。
- 违规项检测：二维码、水印、联系方式、敏感图片、模糊图片、违规内容。
- 缩略图：上传后缩略图 ≥9，确认全部加载。

### 3.2 标题与正文

- 标题：以平台当前限制为准，配置化，默认 ≤20 字。
- 正文：以平台当前限制为准，配置化，默认 ≤1000 字。
- 正文仅填充一次，话题合并一次性写入，杜绝 `contenteditable` 重复写入 Bug。
- 禁止外链、二维码、联系方式、诱导性话术。
- AI 生成内容建议按平台要求标识。

### 3.3 话题、@、地点、合集、可见范围、原创声明

- 话题：数量配置化，默认 ≤10 个；自动替换必须写变更日志。
- @：数量配置化，默认 ≤5 个。
- 地点：搜索选择，不手填无效地点。
- 合集：可选，按账号配置。
- 可见范围：默认公开，人工 B1/B3 可改。
- 原创声明：AI 可填，人工确认。
- 定时发布：AI 不设置；若平台提供，人工 B3 自行决定。

## 5. 状态机与异常恢复

### 5.1 正常状态

`待素材 → 登录中 → 编辑中 → 上传中 → 校验中 → 元数据填充中 → 终验中 → 待人工 → 人工已保存 → 待发布 → 已发布`

### 5.2 异常状态

`登录失败 / 滑块失败 / 短信冻结 / 上传失败 / 图片校验失败 / 终验拦截 / Token 不足 30 分钟 / 浏览器崩溃 / 断网 / 人工中断 / 重复任务`

### 5.3 异常处理表

| 异常 | 重试 | 熔断 | 转人工 | 恢复 |
|---|---|---|---|---|
| 登录失败 | 扫码重试 | 3 次 | 是 | 人工重扫码 |
| 滑块失败 | 3 次 | 是 | 是 | 人工接管 |
| 短信验证码 | 间隔 ≥60 秒 | 连续失败冻结 | 是 | 人工重扫码 |
| 上传失败 | 最多 2 次 | 预上传 30 秒 / 分片 5 分钟 | 是 | 重传或换图 |
| 图片校验失败 | 不重试 | 是 | 是 | 人工换图 |
| 终验拦截 | 低风险自动替换 | 高风险冻结 | 是 | B1 高亮确认 |
| Token 不足 30 分钟 | 告警 | 超时冻结 | 是 | 人工重扫码 |
| 浏览器崩溃 | 不自动重启 | 是 | 是 | 人工恢复草稿 |
| 断网 | 退避重试 | 3 次 | 是 | 人工检查 |
| 人工中断 | 停止 AI 动作 | 是 | 是 | 点击橙色中断按钮，不关闭浏览器 |
| 重复任务 | 幂等去重 | 是 | 是 | 查 `task_id` / sha256 |

## 6. A0-A8 图文特化细则

### A0 准备素材

- 素材仅副本，不改原文件。
- 落本地 JSON，字段见第 4 节。
- 图片按 `order` 排序，指定封面。
- 标题、正文、话题、@、地点、合集、可见范围、原创声明一次备齐。

### A1 启动会话 + 登录校验

- 未登录扫码。
- 滑块重试 3 次，失败冻结转人工。
- 短信验证码重试间隔 ≥60 秒，连续失败冻结转人工。
- 多账号隔离：Cookie、StorageState、代理、IP、账号目录隔离。
- Token 剩余时长小于 30 分钟时，触发飞书/钉钉告警，不自动续期。

### A2 会话稳定与限频基线

- 固定浏览器版本、分辨率、时区、语言。
- 禁用无关插件，减少环境波动。
- 动作加随机延迟，遵守平台频率限制。
- 不承诺规避平台检测；不做恶意绕过。
- 触发风控时冻结转人工。

### A3 进入创作编辑器

- 仅图文入口。
- 多版本选择器，页面状态判断。
- 失败截图保存，便于排查。
- 确认进入编辑器后再执行 A4。

### A4 上传素材

- `setInputFiles` 原生上传。
- 预上传 30 秒超时。
- 分片 5 分钟超时。
- 按 `order` 逐张上传，显示进度。
- 失败重传最多 2 次。
- 上传后确认缩略图 ≥9。
- 重复图按 sha256 去重。

### A5 上传校验

- 强制图片数量 =9 张。
- 格式 JPG/PNG/WebP。
- 宽高比 3:4。
- 单图 ≤20MB。
- 短边 ≥1080px。
- 封面图必须指定。
- EXIF 清理。
- 重复图检测。
- 二维码、水印、联系方式、敏感图片、模糊图片、违规内容检测。
- 缩略图 ≥9，全部加载成功。
- 校验失败转人工，不自动继续。

### A6 填充元数据

- 逐字打字机延迟：80~250ms（高斯随机）。
- 标点停顿：500~1200ms。
- 标题、正文、话题、@、地点、合集、可见范围、原创声明。
- 正文只填一次，话题合并一次性写。
- 填充后真实 DOM `innerText` 校验。
- 不设定时发布。

### A7 发布前终验

- 站内预览 + 大模型初筛。
- 检查：违禁词、外链、联系方式、二维码、话题时效、重复发布、草稿完整性。
- 低风险自动替换，高风险转人工。
- 自动替换必须写变更日志。
- B1 阶段页面顶部高亮提示条展示自动修正记录，并展示修改前后对比内容。
- 终验用真实 DOM 读取 `innerText`，不要依赖快照（snapshot）文本。

### A8 仅存 `draft_id` + 变更日志

- 仅存 `draft_id` + 变更日志。
- Token 剩余时长小于 30 分钟时，触发飞书/钉钉告警，不自动续期。
- 超时冻结等人工重扫码。
- 记录字段：`task_id`、`draft_id`、`step`、`field`、`before`、`after`、`reason`、`operator`、`ts`。
- 不自动发布。

## 7. B1-B4 人工 SOP

### B1 草稿箱 / 预览链接打开

- 顶部高亮提示条显示自动修正。
- 展示修正前后对比。
- 可回滚自动替换。
- 人工确认图片、标题、正文、话题、@、地点、合集、可见范围、原创声明。

### B2 润色修改 → 点保存

- 人工修改优先级最高。
- 点保存触发反读回调 A8 回写本地。
- 冲突处理：以人工修改为准，写变更日志。
- 保存后再次真实 DOM 校验。

### B3 人工点「确认发布」

- 二次确认。
- 发布按钮永留人工。
- AI 不得代点、不得调用发布接口、不得设置定时发布。
- 发布前可再次预览。

### B4 完成

- 回写 `note_id`、URL、发布时间、截图、状态。
- 通知用户。
- 归档发布记录。
- 若发布失败，记录原因，转人工处理。

## 8. 风控、合规、安全

- 遵守平台条款与社区规范。
- 账号隔离：Cookie、Token、StorageState、代理、IP、目录隔离。
- 频率管控：设置每日发布上限、操作间隔、错峰发布策略。
- 内容合规：广告法、医疗金融违禁、外链、二维码、联系方式、诱导话术。
- 版权：图片、字体、音乐、肖像授权。
- AI 生成标识：按平台要求标识。
- 安全：Token 加密存储、脱敏、轮换；日志不记录明文敏感信息。
- 不承诺规避平台检测，不做恶意绕过。
- 触发风控冻结转人工。

## 9. 监控、告警、审计

| 指标 | 说明 |
|---|---|
| 上传成功率 | 单图/整任务 |
| 单图失败率 | 按原因分类 |
| 草稿保存率 | A8 成功 |

| 人工发布率 | 应 100% |
| 发布成功率 | B4 回写 |
| 回写成功率 | `note_id`/URL |

告警分级：P0 冻结、P1 失败、P2 提醒。  
审计日志：所有自动替换、人工修改、发布操作可追溯。
