## 二、利用率指标计算说明

### 2.1 政策依据
按照《国家能源局关于做好新能源消纳工作 保障新能源高质量发展的通知》（**国能发电力〔2024〕44号**）要求，统一新能源利用率统计口径。发电和电网企业严格落实：
- 《风电场利用率监测统计管理办法》（**国能发新能规〔2022〕49号**）
- 《光伏电站消纳监测统计管理办法》（**国能发新能规〔2021〕57号**）

**关键口径：新能源利用率按"仅考虑系统原因受限电量"计算**，剔除了电站自身设备故障、计划检修、并网调试、市场化交易决策不当等"特殊原因"影响，更能真实反映电力系统对新能源的消纳能力。

### 2.2 风电利用率计算

**风电场利用率（仅考虑系统原因）：**
```
风电场利用率 = (风电场可用机组可发电量 − 系统原因受限电量) / 风电场可用机组可发电量
```

**地区风电利用率：**
```
地区风电利用率 = Σ(风电场可用机组可发电量 − 系统原因受限电量) / Σ风电场可用机组可发电量
```

**受限电量：**
```
受限电量 = 受限时段风电场可用机组可发电量 − 受限时段风电场实发电量
```

**系统原因受限电量：**
```
系统原因受限电量 = 受限电量 − 特殊原因受限电量
```
> 系统原因受限电量：风电场受电力系统用电负荷及调峰能力、网架约束、安全稳定运行等因素影响，可发而未能发出的电量。

**风电场可用机组可发电量：** 风电场内除受场内设备故障、缺陷或检修等因素影响的风电机组外，剩余可用风电机组在所处自然条件和设备状态下（不考虑电力系统运行因素影响），在相应时间内理论上可发出的电量。

### 2.3 光伏利用率计算

**单个光伏电站利用率（仅考虑系统原因）：**
```
电站利用率 = (光伏电站可用发电量 − 因系统原因受限电量) / 光伏电站可用发电量
```

**地区光伏电站利用率：**
```
地区光伏电站利用率 = Σ(可用发电量 − 系统原因受限电量) / Σ可用发电量
```

**地区光伏发电利用率（含分布式）：**
```
地区光伏发电利用率 = (Σ(可用发电量 − 系统原因受限电量) + Σ分布式及其他光伏发电项目发电量)
                    / (Σ可用发电量 + Σ分布式及其他光伏发电项目发电量)
```

**受限电量与系统原因受限电量：**
```
受限电量 = 可用发电量 − 实际发电量
系统原因受限电量 = 可用发电量 − 实际发电量 − 特殊原因受限电量
```

### 2.4 特殊原因受限电量（不计入消纳能力评估）

**风电特殊原因（7 类）：**
1. 台风、地震、洪水、覆冰、泥石流等不可抗力导致出力受限；
2. 并网调试 / AGC 测试阶段、临时方案接入超送电极限、出力超场站并网调度协议装机容量；
3. 并网技术条件不满足相关标准或违反并网管理要求整改；
4. 送出输变电设备正常计划检修；
5. 市场化方式并网风电场未落实并网条件；
6. 市场化交易决策不当；
7. 场站外重大工程施工、重大社会活动、特殊保电任务。

**光伏特殊原因（7 类）：**
1. 台风、地震、洪水等不可抗力未能发出的电量；
2. 送出线路计划检修未能发出的电量；
3. 出力超出电站备案容量（交流侧容量）未能发出的电量；
4. 处于并网调试期未能发出的电量；
5. 并网技术条件不满足标准或依规整改期间未能发出的电量；
6. 市场化方式并网未落实并网条件；
7. 市场化交易决策不当。

> 多种特殊原因同时产生时，风电按主要原因归纳为一类；光伏按排序较前的单一情况归纳，避免重复统计。
