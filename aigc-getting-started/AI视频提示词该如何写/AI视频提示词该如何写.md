# AI 视频提示词该如何写

> 📌 说明：原海报逐字转录的正文各章节已按要求删除；以下仅保留整理者归纳、补充的内容。原图仍保存在本文件夹，可随时恢复。

## 核心思路（整理归纳）

**先学造句，再学提示词**。AI 视频的本质是"语言转视觉"——把脑海中的想法用语言描述清楚，AI 才能把它变成视觉场景 + 动态画面 + 完整视频。

## 术语勘误（整理补充）

> ⚠️ 原海报把「特写」归到「视角」、把「推拉」单列为「动态」，均与通用影视术语不符。规范分类如下：
>
> - **景别**：远景、全景、中景、近景、特写
> - **角度**：平视、俯视、仰视（「视角」另含主观视角）
> - **运镜**：推、拉、摇、移、跟、升降
> - **镜头运动**：固定、手持、稳定器跟拍

## 速查卡（整理补充）

写 AI 视频提示词时，按这个清单逐项检查：

**前四步 · 写好提示词**

- [ ] **主体**：谁 / 什么？外貌、服装、特征
- [ ] **动作**：正在做什么？节奏如何？
- [ ] **环境**：地点、时间、天气、背景
- [ ] **细节**：光线、色彩、氛围、物体
- [ ] **镜头**：景别、角度、运镜、镜头运动（按规范四类，见术语勘误）
- [ ] **动态**：人物／物体动作、镜头运动、环境变化；设定节奏

**第五步 · 生成与调整**

- [ ] 生成后**看结果**：是否满意？
- [ ] **找问题**：哪里不对？
- [ ] **改句子**：优化细节或镜头
- [ ] **再生成**：直到满意

> 先学造句，再学提示词 —— 把句子造好、把内容写丰富、把镜头说清楚，让画面动起来，再不断调整到满意。
