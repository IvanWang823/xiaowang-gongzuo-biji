## 一、AI生图和视频原理（简析）

- **生图核心 = 提示词与图片的共生关系**：提示词生成图片，图片也可反向拆解还原提示词，二者形成"文字→图像→文字"的闭环。
- **生视频 = 生图的进阶**：视频由多张连续图片构成，AI 通过生成一系列连贯图像形成动态内容；图像来源既可是实拍素材，也可是纯 AI 生成画面。
- **应用场景**：电商产品图/视频、AI 短剧等商用需求持续增长。

---

## 二、为什么需要标准化管理

核心转变：从依赖个人经验的"作坊式"单打独斗 → 全流程可控的"工业化"流水线作业。

三大价值：
1. **文件清晰可查**：杜绝"素材(1).mp4"式混乱命名，任何人都能第一时间定位文件。
2. **支持高效协作**：设计师、提示词工程师、配音、剪辑共用一套标准语言，降低跨岗位沟通成本。
3. **批量高效处理**：标准命名与 Excel 总表无缝关联，可批量生成脚本、批量替换素材、自动导出成片。

## 三、项目文件夹结构规范

### 3.1 标准根目录（数字前缀保证自动排序）

```
项目名称_20260521/
├── 1_角色素材/     # 角色标准图、三视图、表情、细节图
├── 2_分镜图/       # 分镜草图/参考图（只放图片，严禁混入视频）
├── 3_分镜视频/     # AI 生成的原始视频片段（未剪辑、无字幕）
├── 4_配音素材/     # 解说词/配音音频（mp3）
├── 5_视频封面/     # 各种比例的封面图
├── 6_成品/         # 最终导出的完整视频
└── 7_项目文档/     # Excel 总表、规范文档、沟通纪要
```

简化版（小项目）：`项目名称/角色素材 + 分镜图 + 分镜视频 + 配音素材 + 视频封面 + 成品`

### 3.2 各文件夹命名规则

| 文件夹 | 命名格式 | 示例 |
|---|---|---|
| 1_角色素材 | 按角色 ID 建子文件夹 `C01_角色名/`，文件 `角色ID_角色名_视图类型[_变体].扩展名` | `C01_小深_标准图.png`、`C02_骑士_动作_拔剑.png` |
| 2_分镜图 | `镜头编号_内容描述.扩展名`（推荐扁平化，不按场景分文件夹） | `镜头01_小深出场.jpg` |
| 3_分镜视频 | `镜头编号_内容描述_v版本号.mp4` | `镜头01_小深出场_v1.mp4`、`_v2.mp4` |
| 4_配音素材 | 按场景 `SC01.mp3` 或按镜头 `镜头03_解说词.mp3` | `SC01.mp3` |
| 5_视频封面 | `封面_比例_版本.png` | `封面_16x9_v2.png`、`封面_竖3x4.png` |
| 6_成品 | `项目名称_最终版.mp4` 或 `视频标题_final.mp4` | `AI宣传片_最终版.mp4` |
| 7_项目文档 | 存放总表、规范 PDF、纪要 | `AI视频制作总表.xlsx` |

**封面比例对照**：`16x9` 横版（YouTube/B站）、`4x5` 竖版（小红书）、`1x1` 方版（视频号）、`9x16` 手机全屏（抖音）。**3:4 与 4:3 必须写"竖3x4"/"横4x3"区分**。

## 四、角色库与分镜库编号规则

### 4.1 角色库

- **角色 ID**：`C` + 两位数字（C = Character），全局唯一，如 C01、C02。与本地素材文件夹命名严格一致。
- **视图类型关键词（统一规范）**：

| 视图类型 | 关键词 | 示例文件名 |
|---|---|---|
| 标准正面像 | 标准图 | `C01_小深_标准图.png` |
| 三视图 | 三视图 | `C01_小深_三视图.jpg` |
| 表情 | 表情_具体表情名 | `C01_小深_表情_高兴.png` |
| 动作/姿态 | 动作_具体动作名 | `C02_骑士_动作_拔剑.png` |
| 细节特写 | 细节_部位描述 | `C01_小深_细节_左臂标记.png` |
| 配色/色板 | 色板 | `C01_小深_色板.png` |

- 严禁不同角色素材混放；角色图优先 `.png`（支持透明背景）。

### 4.2 分镜库

- **场景 ID（可选前缀）**：`SC` + 两位数字，如 SC01、SC02，仅用于多场景逻辑分组。
- **镜头 ID（核心索引）**：`镜头` + 两位数字，全局递增，**必须与 Excel 分镜表镜头编号严格一致**。
- **命名格式**：`[场景ID_]镜头ID_内容描述.扩展名`
  - 示例：`SC01_镜头01_小深出场.jpg` 或 `镜头01_小深出场.jpg`
- **描述关键词参考**：`角色名_动作`（小深_回头）、`景别_对象`（特写_骑士眼睛 / 远景_城堡）、`运镜方式`（推近_小深面部 / 横移_战场）
- 推荐**扁平化**结构，不用"第一幕/第二幕"等中文目录（不利于跨平台同步与 AI 工具识别）。
- 版本管理：多草稿版本加 `_v1`、`_v2`，Excel 只链接最新版本。

### 4.3 两库与 Excel 的对应关系

- 角色库 → 分镜表"角色ID"列，可用 VLOOKUP 带出角色图路径。
- 分镜库 → 分镜表第一列直接写"镜头01"，用 HYPERLINK 函数生成图片链接：
  `=HYPERLINK("./分镜图/" & A2 & "_" & B2 & ".jpg", "查看分镜")`（A列=镜头编号，B列=简短描述）

## 五、Excel 总表设计（核心管理工具）

- **定位**：项目的信息中枢与唯一事实来源（Single Source of Truth）。
- **文件名**：`项目名称_制作总表.xlsx`（例：`数字人科普_制作总表.xlsx`）
- **工作表结构**（按顺序至少 3 个）：① 角色表 → ② 分镜表 → ③ 台词表（可选，长文本/做字幕时必备）

### 5.1 角色表字段

| 字段 | 必填 | 说明 | 示例 |
|---|---|---|---|
| 角色ID | ✅ | 唯一编号，与文件夹一致 | C01 |
| 角色名称 | ✅ | 中文名 | 小深 |
| 角色描述 | 可选 | 简短特征 | 蓝色机器人，友好 |
| 角色图路径 | ✅ | 超链接 | `./角色素材/C01_小深_标准图.png` |
| 三视图路径 | ✅ | 超链接 | `./角色素材/C01_小深_三视图.jpg` |
| 生成提示词 | 推荐 | 用于复现 | a cute blue robot, front view... |
| 种子/参数 | 可选 | 关键参数 | seed:12345, cfg:7 |
| 一致性标记 | 可选 | 需统一的特征 | 左臂有红色标记 |
| 状态 | 可选 | 草稿/定稿 | 定稿 |
| 备注 | 可选 | 其他说明 | 三视图需重新生成 |

简化版 7 列：角色ID、角色名称、角色图、三视图、生成提示词、状态、备注。

### 5.2 分镜表字段（核心）

| 字段 | 必填 | 说明 | 示例 |
|---|---|---|---|
| 镜头编号 | ✅ | 全局唯一，与文件名一致 | 镜头01 |
| 场景编号 | 可选 | 用于分组 | SC01 |
| 内容描述 | ✅ | 画面动作/构图/运镜 | 小深出场，正面站立，镜头缓慢推进 |
| 角色ID | ✅ | 关联角色表 | C01 |
| 分镜图路径 | ✅ | 超链接 | `./分镜图/镜头01_小深出场.jpg` |
| 分镜视频路径 | ✅ | 超链接（指向最新版本） | `./分镜视频/镜头01_小深出场_v2.mp4` |
| 台词/解说词 | 推荐 | 该镜头文本 | 大家好，我是小深 |
| 配音素材路径 | 可选 | 超链接 mp3 | `./配音素材/SC01.mp3` |
| AI生成提示词 | ✅ | 生成该视频的 Prompt | a blue robot standing... |
| 负向提示词 | 可选 | 不想出现的内容 | blur, low quality |
| 参数设置 | 可选 | 种子、CFG、步数 | seed:12345, cfg:7 |
| 时长(秒) | 推荐 | 纯数字 | 6 |
| 状态 | ✅ | 进度跟踪 | 计划中/生成中/已完成/需重做 |
| 备注 | 可选 | 特殊说明 | 注意铠甲反光 |

简化版 9 列：镜头编号、内容描述、角色ID、分镜图、分镜视频、台词、AI提示词、时长、状态。

### 5.3 台词表字段（可选）

| 字段 | 说明 |
|---|---|
| 台词ID | 唯一编号，L01、L02… |
| 对应镜头编号 | 关联分镜表，如 镜头01 |
| 台词类型 | 旁白/对话/解说词 |
| 说话角色 | 小深、旁白 |
| 台词内容 | 完整文本（无错别字） |
| 时长(秒) | 预估，如 3.5 |
| 对应音频文件 | 超链接 mp3 |
| 字幕时间码 | 格式 `00:00:01.000`（HH:MM:SS.FFF） |
| 字幕样式 / 状态 / 备注 | 可选 |

**做字幕专用格式**（可导入剪映/Arctime）：字幕编号 | 开始时间 | 结束时间 | 台词内容 | 对应镜头

### 5.4 关键规则（铁律）

1. **时长填写铁律**：必须写纯数字（`6`、`3.5`），**禁止写 `00:06`**（文本格式无法求和）。如需显示时分秒，另加辅助列 `=TEXT(A2/86400, "mm:ss")`。
2. **超链接管理**：右键→超链接，或 `=HYPERLINK("路径","显示文字")`；团队协作统一用相对路径；新版本生成后第一时间更新链接。
3. **状态下拉菜单**：选中列 → 数据验证 → 序列 → 输入 `计划中,生成中,已完成,需重做`。
4. **编号一一对应**：分镜表镜头编号 ↔ 分镜图/视频文件名中的编号完全一致，统一两位数（镜头01、镜头02…）。
5. **同图不同氛围**：分镜图相同但情感不同时，复制提示词后微调关键词（如 happy → intense）。

### 5.5 实用小技巧

- 快速生成文件清单核对（Windows）：目标文件夹内 Shift+右键 → 打开 PowerShell → `dir /b > list.txt`，核对文件名与 Excel 镜头列表是否一致。
- 一致性检查：定期核对分镜表"镜头编号"列 ↔ 分镜图文件夹文件名，可用条件格式标记缺失文件。

## 六、协作指南（多人项目）

### 6.1 角色与职责

| 角色 | 职责 |
|---|---|
| 项目负责人 | 维护 Excel 总表，制定版本号，审核成品，统筹进度与资源 |
| 角色设计师 | 生成角色图、三视图，把控视觉风格，更新角色表 |
| 分镜师 | 绘制分镜图，填充分镜表（内容描述、提示词初稿），确定镜头语言 |
| AI视频生成 | 按分镜表逐镜头生成视频，上传并更新路径与状态 |
| 配音/音效 | 提供高质量 mp3，匹配口型情绪，建立音画关联映射 |
| 剪辑/后期 | 合成音视频、调色特效，制作成片和封面，完成交付 |

### 6.2 协作流程（六步闭环）

1. **项目启动**：负责人创建文件夹结构 + Excel 总表。
2. **角色设定**：设计师完成角色图 → 更新角色表。
3. **分镜与台词**：分镜师填分镜表 + 绘分镜图 → 上传。
4. **AI生成**：按分镜表逐镜头生成 → 更新视频路径 + 状态。
5. **配音同步**：配音提供 mp3 → 分镜表关联。
6. **最终合成**：剪辑导出成品 → 更新成品文件夹，总表归档。

### 6.3 版本管理规则

| 对象 | 规则 | 原则 |
|---|---|---|
| 分镜视频 | `镜头XX_描述_v1.mp4` → v2 → v3 → `_final` | 每次迭代存新文件，**严禁覆盖旧版本** |
| 最终视频 | `项目名_v1.0.mp4` → v1.1（小改）→ v2.0（大改） | 语义化版本号 |
| Excel总表 | `制作总表_20260522.xlsx`（注明修改日期） | 优先用 OneDrive/腾讯文档/飞书云协作 |

### 6.4 交接检查清单

- [ ] 分镜表"状态"列已更新？
- [ ] 新增文件已按规范命名并放入正确文件夹？（杜绝散落桌面/临时目录）
- [ ] 超链接能否正常打开？（相对/绝对路径一致）
- [ ] 提示词与参数记录完整？（保证复现性）

## 七、常见问题速查表

| 问题 | 正确做法 |
|---|---|
| 分镜图和分镜视频放一起？ | 不许。图在 `2_分镜图`，视频在 `3_分镜视频` |
| 同一镜头多个版本怎么命名？ | `镜头01_小深出场_v1.mp4`、`v2.mp4`，禁止覆盖 |
| 时长格式 | 写 `6`，不写 `00:06` |
| 3:4 与 4:3 记混 | 文件名写"竖3x4"或"横4x3" |
| 角色图/三视图太多放不下 | 角色表用超链接列，一个字段多个文件用分号隔开 |
| 解说词只有 mp3 没文字 | 先转录文字填入台词表，再关联 |
| 多人共用一个 Excel | 用云盘（OneDrive/腾讯文档/飞书）在线协作 |
| 总 Excel 文件叫什么 | `项目名_制作总表.xlsx` |

## 九、标准化管理的四大收益（总结）

1. **提升效率**：减少查找、确认版本的无效时间，聚焦创作本身。
2. **保证质量**：统一角色设定与分镜管理，规避风格不统一、形象割裂。
3. **降低成本**：清晰的规则是协作"通用语言"，新成员快速上手，减少返工。
4. **沉淀资产**：结构化数据支撑复盘迭代，经验转化为可复用知识资产。
