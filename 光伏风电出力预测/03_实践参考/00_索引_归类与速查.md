## 三、使用建议

1. **要方法选型** → 主报告 §12.1（谱系表）+ §12.2（风电五类），深读 `清徕美` / `AlphaEmpower`。
2. **要数据治理 / 限电处理** → 主报告 §12.3 + 建模七步第 1 步，深读 `清徕美` §3 + `申威睿思` §2。
3. **要概率预测落地** → 主报告 §12.4，深读 `申威睿思` §3 + `AlphaEmpower` §4 + `行业标准` §5。
4. **要合规对标** → 主报告 §二/§六 + §12.7，深读 `行业标准与精度基准` + `GEFCom`。
5. **要物理法引擎 / 数据源** → 主报告 §三 + §12.5，深读 `晴川观象`。
