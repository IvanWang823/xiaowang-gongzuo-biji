## 一、核心理论框架

- **NWP（数值天气预报）物理模型**：WRF、ECMWF（IFS）、GFS 通过求解大气动力学方程组输出温度 / 气压 / 风速 / 云量 / 辐照度；新能源预测用高分辨率区域模式将网格从数十公里加密到 **1–3 km**，并耦合地形、下垫面、边界层参数化方案。作用：提供未来气象边界条件（短–中期预测基石）。
- **统计与机器学习「纠偏」**：NWP 存在系统性偏差（如特定地形导致高估风速约 10%），用 XGBoost / LightGBM / CatBoost / Random Forest / LSTM / GRU 将历史 NWP 输出与实际功率映射，建立误差补偿模型；融合实时观测（测风塔、卫星云图、雷达、组件背板温度）滚动更新。
- **集合预报与概率预测**：大气混沌性使单点确定性预报必含误差；扰动初始场 / 参数化生成数十–上百等概率情景，输出分位数 / 概率密度（如「80% 概率出力在 200–260 MW」），直接支撑备用容量安排与风险对冲。**工程表达即 P10 / P50 / P90 分位预测**（P50 为核心点预测，P10–P90 为不确定区间）；区间须做**共形校准（Conformal Prediction / ACI 自适应共形推断）**，否则区间会过宽或过窄而失真（详见 `../03_实践参考/申威睿思_功率预测平台方法论参考.md` 第三、四节）。
- **混合 / 堆叠策略**（文献中最常见设计模式）：分解（小波 / 频域）+ ML，或多 NWP 源 stacking 集成（HEFTCom2024 冠军方案即「多 NWP 源 stacking + GBDT 主模型」）。

## 三、权威数据源 / 机构

- **NWP 原料**：ECMWF、NOAA GFS、中国气象局；公开 API 可选 **Open-Meteo**、**ECMWF IFS / GFS / ICON**（详见 `../03_实践参考/晴川观象_物理模型工具链参考.md` 第四节）
- **电站目录**：**Global Energy Monitor (GEM)**、**WRI Global Power Plant Database**（场站位置/类型/装机容量公开底表）
- **卫星影像**：日本气象厅 **Himawari-9（葵花九号）**（云图、辐照辅助）
- **方法验证基准（公开数据集）**：全球能源预测竞赛 **GEFCom**（2012 风电 / 2014 风电+光伏双赛道 / 2017 负荷），数据集随主办方论文公开，是光伏/风电功率预测的学界标准基准；数据集结构与三篇奠基论文见 `../03_实践参考/GEFCom数据集与基准参考.md`，对应文献清单 #14–#16 / HEFTCom
- **中国技术标准（合规底线）**：**GB/T 40607-2021**（风电场功率预测系统技术规范，短期月均方根误差≤25%）、**NB/T 31046—2022**（风电功率预测系统功能规范，超短期≤20%/短期≤25%）、**NB/T 32031—2025**（光伏发电功率预测系统功能规范，2026-03-28 实施）；以「全国标准信息公共服务平台」官方文本为准（详见 `../03_实践参考/行业标准与精度基准参考.md` 第二、三节）
- **行业标杆**：丹麦 Energinet、德国 50Hertz 等 TSO 公开预测性能报告

## 四、本项目落点（与本分析对应）

- 本项目的「分析思路」若覆盖超短期 / 短期 / 中期多时间尺度，应按 **「NWP 物理 → ML 纠偏 → 概率预测」三层**对应；长期尺度更依赖 NWP 与混合设计。时间尺度采用行业通用分段：**超短期 0–4 h / 短期 0–72 h / 中期 0–14 d**（详见 `../03_实践参考/申威睿思_功率预测平台方法论参考.md` 第一节）。
- 评估指标务必用 MAE/RMSE + **扩展窗口交叉验证**，杜绝信息泄露（leakage）。
- 方法选型可引用 GEFCom / HEFTCom 作为同行基准（树集成为主、序列模型为辅、概率预测必备）。
