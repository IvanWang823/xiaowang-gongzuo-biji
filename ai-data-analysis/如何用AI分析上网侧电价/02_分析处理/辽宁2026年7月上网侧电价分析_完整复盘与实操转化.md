## 二、关键突破：数据源

**原计划（方案B）读北极星电力市场网周报折线图取点 → 走不通**：周报图表只在微信公众号 mmbiz 图里，网页版 HTML 纯文字、图表被剥离，无法读像素取点。

**改用辽宁省发改委官方真源（超额完成）**：

- 接口：`https://fgw.ln.gov.cn/indexview/api/getLine`
- 方法：**POST**，请求体 `{"date":"YYYY-MM-DD"}`
- 返回：`data.before`（日前 96 点）+ `data.realTime`（实时 96 点），单位 元/MWh
- 逆向过程：先发现 `indexview` 是 Vue SPA（curl 只拿框架页）→ Playwright 渲染抓网络请求 → 锁定 `getLine` 为 POST 接口
- 抓取结果：**31 天全部成功**，原始 JSON 存于工作区 `ln_raw/2026-07-XX.json`（31 个文件）

> 交叉验证：与北极星周报极值一致（如 7.12 日前均 −82.18、7.16 实时均 −43.29 正对应周报最低值）。

> ⚠️ 口径注记：辽宁 4.0 规则下日前市场暂停结算，`data.before` 实为「预出清参考价」而非结算价；实时 `data.realTime` 为实际出清价。分析中以实时价为主口径，日前价作参照。

## 五、核心分析结论

### 5.1 整体水平

- 月均（日前 / 实时）：**219.85 / 204.18** 元/MWh
- 实时价负价天数 **24/31（77%）**；−100 价格下限被触发 **342 次（实时）/ 139 次（日前）**
- 最低单日均价：日前 −82.18（07-12）、实时 −55.71（07-12）
- 最高单日均价：日前 359.65（07-19）、实时 405.46（07-24）

### 5.2 负电价成因（四层）

1. **数据指证（双谷指纹）**：午间 08–15 时（实时负价占比峰值 65–68% @14–15，光伏带）+ 夜间 21–05 时（29–42%，风电带）；18–20 时相对干净
2. **机理**：现货按边际成本出清，风光零边际成本优先消纳 → 净负荷塌陷 → must-run 机组贴钱上网
3. **辽宁 7 月具体成因**：光伏午间峰 + 风电夜间峰；新能源已是第一大电源（装机 4273 万 kW、占比 45.22%，按 2025 末口径风+光 3758 万 kW/41.1%，2026 新投几乎全新能源，反超是趋势）；实时比日前更负 = 预测偏差被纠偏
4. **诚实边界**：仅价格数据，负价因果为「时段指纹强推断 + 气象量化相关」，非回归闭环

### 5.3 气象代理实证（§4.6）

- 风速 ↔ 实时价 **r=−0.487**（夜间 21–05 **r=−0.553**）→ 主导负驱动
- 短波辐射 ↔ 实时价 r=−0.194（午间近乎零 +0.047，被高制冷负荷抵消）
- 风速四分位→实时均价：Q1 315 / Q4 **61.1**（单调降）
- 把「双谷指纹推断」升级为「气象—价格量化同步证据」

### 5.4 电价 vs 全社会用电量

- 机理：价由「净负荷=负荷−新能源」边际出清决定，负荷是输入之一但被新能源剧烈搅动，非线性
- 数据现实：全社会用电量公开口径为**月度总量**，无日度/逐时序列 → 与 96 点电价**口径错配，无法直接相关**
- 代理检验：工作日实时均 202.6 vs 周末 208.6，无单调趋势；负价日散布各星期 → 周末工业负荷降未带来价格降
- 反例：7/31 辽宁负荷创纪录 4585 万 kW，但当日实时日均仅 4.76（近零）、负价点 143 → 新能源注入压倒负荷成主导
- **结论**：在辽宁新能源第一大电源结构下，「用电量↑→电价↑」在月度/日均层面不成立

### 5.5 偏差复盘（§4.7）

- 日前日均 ↔ 实时日均 **r=0.707**（整体同向）
- 全月 **41.2%** 的 15 分钟点实时价 < 日前价（日内频繁纠偏）
- 实时价频带：**负价 31.1%** / 300–400 占 **54.1%** → 结构性两极（高价常态 + 深负插针）

> ⚠️ **偏差分析定位澄清（重要）**：辽宁 4.0 规则下**日前市场暂停结算**，`data.before` 是「预出清参考价」而非结算价。因此本节「日前 vs 实时偏差」的实质是 **「预出清参考价 ↔ 实时出清价」的预测纠偏偏差**，反映日前市场对实时出清的**方向性高估 / 低估**（即现货价格的可预测性），**不是财务层面的结算损益偏差**。
> - 41.2% 时点实时 < 日前 → 说明日前（预出清）对实时出清**系统性偏高估**，即「实时往往更便宜」，与新能源大发时段现货价被打低一致。
> - 该偏差**不能**直接换算成日前申报的考核费或损益；真要计算偏差考核费用，需用户补充节点电价 + 日前申报曲线（见第九、十二节）。

### 5.6 储能理论套利（§4.8，假设 4h 储能、效率 90%、低 4h 充高 4h 放）

- 日均套利价差 **341.8** 元/MWh，单 MW 日理论利润 **1215 元**
- **100 MW/400 MWh 电池 7 月理论套利 ≈ 376.6 万元**
- 单日极差：最强 07-02（价差 831、日利润 3026 元/MW）/ 最弱 07-21（价差 42.8、日利润 31）
- ⚠️ 为价格理论上限，非实际收益

### 5.7 辐照深挖（§4.6.1）

- 原「辐照↔实时价 r=−0.194（弱）、午间 +0.047（近零）」是真算的，但单看这个数会轻描淡写甚至误导
- 深挖四角度证明 **光伏确实显著压低电价**（简单相关被「混杂效应」洗平）：
  - **典型日轮廓**：14:00 辐照 624 W/m² → 实时价 **85.8（全月最深谷）**；18:00 太阳落山价弹回 **321** —— 辐照峰与价格谷时间严丝合缝
  - **风×光交互**：高光低风 274 vs 低光低风 304 → 光伏独立压价约 **30 元/MWh**；叠加风电最狠（高光高风=100）
  - **逐时相关**：06–17 多数转正/近零（晴天=热=高制冷负荷抵消光伏压价）；18–20 转负 —— 这正是简单相关被洗平的根因
  - **分位数 & 日前价**：辐照 Q4 实时均价最低 **143.5**；辐照↔日前价 r=−0.311 比 ↔实时价更负（日前市场已"预见"光伏）
- 结论：光伏压价真实可观，被「晴天同时推高制冷负荷」反向因素在数学上盖住

### 5.8 辽宁电源分布（对话 + 地图）

- **装机结构（2025 末全口径，辽宁省电力交易中心）**：火电 4225 万 kW/46.23%、风电 2203/24.10%、太阳能 1555/17.01%、核电 671/7.34%、水电 486/5.31%，合计 9140
  - 更正：早期对话称「新能源(4273万kW、45.22%)超火电成第一大电源」是某 2026 口径；按 2025 末权威口径火电仍略大于新能源(风+光=3758、41.1%)，但 2026 新投几乎全新能源，反超是趋势
- **风电分布**：辽西北陆上（阜新/朝阳/铁岭占 58%+）+ 沿海海上（大连庄河 150 在运+规划 390 / 营口盖州 / 葫芦岛绥中）

### 5.9 价格形成机制：边际出清与出清时序（详见下册第十六章）

### 5.10 中长期合约与差价结算（报告第五章）

- 中长期合约是「金融差价合约」：签约价与现货月均的**差价**结算，对冲现货波动，不直接决定物理发用电
- **辽宁 4.0 口径：年度+月度中长期签约比例 ≥ 70%**（早期误写 90%，已据辽宁 4.0 本地规则修正为 70%）
- 对电厂意义：70% 电量锁价，余下 30% 暴露现货 → 现货深负会侵蚀现货段收益，但中长期段托底
- 与本次分析衔接：本报告现货价用于「现货段收益情景估算」，不能替代合约台账

### 5.11 其他价格机制：辅助服务 / 容量电价 / 监管（报告第六章）

- **辅助服务（深度调峰）**：约 **0.30 元/kWh**，是火电在新能源大发时压负荷的补偿来源，与现货负价互为表里
- **容量电价**：煤电容量电价约 **165 元/kW·年**（辽发改价格字〔2026〕2 号口径，需用户核对红头原文），保障机组固定成本回收，与电量电价解耦
- **市场监管**：现货价格笼子 −100~1500 元/MWh（本报告实测触顶 16 次/触底 342 次即落于笼内）；偏差考核、信息披露等规则约束市场力
- 衔接：容量电价 + 辅助服务 + 现货 + 中长期，构成辽宁「四轨价格」。本报告聚焦现货一轨，其余三轨为政策框架性说明

## 十四、实操转化补充（假设情景 · 非真实账）

> **性质声明**：本节基于已抓取的**真源价格数据**（31 天×96 点），做「假设机组参数」的情景推演，把价格翻译成「对不同市场主体意味着什么」。
> **所有机组成本、出力系数、合约比例、利用小时均为假设值**，仅用于演示方法论。要得到贵厂真实账，须用真实台账替换假设（见各小节「诚实边界」）。
> 配套真源分析见 `辽宁省上网侧电价2026年7月分析报告.md`（九章）与本目录其他交付物。

### 14.1 一页纸高管摘要（5 条核心结论）

1. **价格进入「深负 + 高价」两极新常态**：7 月实时均价 204.18 元/MWh，但 **24/31 天出现负价**，`−100` 下限被触发 **342 次**；同时晚高峰触顶 16 次。波动剧烈、不可轻视。
2. **负价根因是「新能源结构性挤出」，不是负荷低**：双谷指纹（午间光伏带 + 夜间风电带）清晰；反例——7/31 负荷创纪录 4585 万 kW，实时价仍贴地（日均 4.76）。「用电量↑→电价↑」在本省结构下不成立。
3. **风电是实时价主导负驱动**：风速↔实时价 夜间 r=−0.553；光伏压价确凿存在，但被「晴天同时推高制冷负荷」在统计上洗平（深挖四角度已证伪"弱相关"）。
4. **电厂收益靠「四轨」托底，现货低 ≠ 电厂亏**：现货深负被 中长期（年度竞价 306.59 元/MWh）+ 容量电价（煤电 165 元/kW·年）+ 深度调峰（0.30 元/kWh）对冲。
5. **行动三件事**：① 核对辽宁 4.0 合约台账，看贵厂现货敞口比例；② 负价时段主动调峰拿辅助补偿，而非硬扛上网；③ 用本报告脚本每月自跑，建立价格监控基线。

### 14.2 三类机组收益画像（火电 / 风电 / 光伏 · 假设情景）

#### 14.2.1 假设前提（全部为演示用假设，必须替换）

| 参数 | 火电 | 风电 | 光伏 | 来源/说明 |
|---|---|---|---|---|
| 边际（燃料）成本 | 280 元/MWh | 0 | 0 | 火电为辽宁褐煤到厂估算；风光边际成本≈0 |
| 7 月现货结算均价 | 204.18（实时） | 204.18 | 175.00 | 风/火按实时月均；**光伏因出力集中午间负价高峰，假设均价被拖更低** |
| 容量电价折算度电 | +36.7 | 0 | 0 | 165 元/kW·年 ÷ 4500h（煤电适用，风光无） |
| 深度调峰补偿 | +45.0 | 0 | 0 | 假设全年 15% 电量参与深度调峰，0.30 元/kWh=300 元/MWh |
| 中长期托底 | 未计入（单列） | 未计入 | 未计入 | 辽宁 4.0 约 70% 电量锁价，此处仅算现货段 |

> *光伏现货均价 175 元/MWh 的推演依据：假设光伏出力集中于 09–16 时（占全天约 85%），以该时段实时价加权计算得约 170–180 元/MWh 区间，175 取中值；此为「基于真源价格 × 假设典型出力系数」的模拟均值，非光伏真实结算均值。*

#### 14.2.2 测算结果（每 MWh 综合收益 · 现货段示意）

| 机组 | 现货收入 | − 成本 | + 容量 | + 调峰 | **综合** | 解读 |
|---|---|---|---|---|---|---|
| 火电 | 204.18 | −280.00 | +36.7 | +45.0 | **+5.9** | 现货段亏，四轨托底后**微利** |
| 风电 | 204.18 | 0 | 0 | 0 | **+204.2** | 零成本，均价即毛利，远高于火电 |
| 光伏 | 175.00 | 0 | 0 | 0 | **+175.0** | 午间负价集中拖拽，略低于风电 |

#### 14.2.3 关键洞察

- **火电的"亏"在现货段，不在综合段**：燃料成本 280 > 现货均价 204，单看现货必亏；但容量电价 + 调峰补偿把综合拉回微利。**这解释了为什么现货频现负价、火电却仍在发**——固定成本已通过容量电价回收，边际上只要实时价 > 燃料变动成本就愿发（且供热机组无法停机）。
- **风光"赚得多但脆弱"**：零成本使其对均价高度敏感。一旦现货全面深负（如 7/12 实时日均 −55.71），风光若按实时全结算，单位收益直接转负——除非有中长期保价托底。
- **中长期是分水岭**：若贵厂签约比例高（辽宁 4.0 本地 ≥70%），则现货段波动被锁价吸收，综合收益稳定；若现货敞口大，则高度暴露。

> **⚠️ 14.2 节所有收益数字均为演示用假设情景，不是对辽宁任何电厂真实经营情况的核算或推断。粗读时请勿将「火电综合 +5.9 元/MWh」等数字抽离上下文当作真实收益结论。**

#### 14.2.4 诚实边界

- 上述数字**全部基于假设的成本/利用小时/补偿参与率**，非贵厂真实账。
- 未计入：机组启停成本、辅助服务其他品种（调频/备用）、输配电价、税费、合约具体分解曲线。
- **要算真账**：给我 ① 节点/结算电价（非全省均价）② 贵厂实际出力曲线 ③ 合约明细（签约价/比例/电量），我按第九节「全数据能力」第 2–3 项做精确结算。

### 14.3 负电价对不同市场主体的损益映射

> 定性映射，基于本报告价格特征 + 公开市场规则（辽宁 4.0 / 东北辅助服务 / 辽发改价格字〔2026〕2 号）。非精确核算。

#### 14.3.1 火电（承压但有多层缓冲）
- **受损点**：负价时段（尤其夜间风电带、午间光伏带）若硬扛上网，实时结算价破零甚至 −100，边际上亏燃料变动成本。
- **对冲层**：
  - ① **容量电价**（165 元/kW·年）：固定成本回收，降低对电量电价的依赖；
  - ② **深度调峰补偿**（0.30 元/kWh）：主动降出力而非硬发，反而拿补偿（负价时段降出力补偿 300 元/MWh > 硬发亏的 −100）；
  - ③ **中长期托底**（≥70% 锁价）：现货段仅是小头。
- **净判断**：现货深负对火电是「电量段承压」，但综合收益受容量+辅助+中长期三层保护，**不构成生存级冲击**。

#### 14.3.2 风电 / 光伏（零成本但被"锁死在发电侧"）
- **受损点**：边际成本 0，但按实时结算时，负价时段出力越多、单位结算价越低（甚至负）。午间光伏负价占比峰值 65–68%，是风光最痛的时段。
- **"弃电更划算"临界点**：理论当实时价 < 0 且弃电无罚时，弃电（收益 0）优于硬发（收益 <0）。**但现实受「保障收购 + 消纳责任」约束，不能随意弃**，导致风光在负价时段"发得越多、账面机会成本越高"。
- **对冲层**：靠**中长期保价**（若签了年度/月度锁价，现货负不影响该部分收益）+ 部分省份的"低价时段优先消纳"机制。
- **净判断**：无保价的新能源在深负月**现货段显著受损**；有高比例中长期托底则影响有限。这是新能源投资回收的隐性风险点。

#### 14.3.3 售电公司 / 大用户（负价时段是获益方）
- **售电公司**：从发电侧购电成本随现货下探而降低，若售予用户的合同价相对刚性（如年度框架），价差扩大 → **负价利好购电侧**。
- **大用户**：负价时段用电 = 电费成本下降甚至理论上的"负电价购电"（用户侧目录电价通常不出现负，但现货市场购电方在负价时段结算成本极低）→ 峰谷套利、储能充电时机优化空间大。
- **净判断**：负价结构是**发电侧向用电侧的价值转移**，用电主体是隐性获益者。

#### 14.3.4 系统 / 电网（平衡成本上升）
- 负价频现 = 系统灵活性资源稀缺信号，需更多储能、调峰、跨省外送消纳。
- 平衡成本通过**辅助服务资金池**（由用户用电量 + 未参与电能量市场上网电量分摊）回收，最终由全体用户共同承担。

#### 14.3.5 临界点与行动建议（客观描述，非决策建议）

| 主体 | 关键临界点 | 可行动作（客观） |
|---|---|---|
| 火电 | 实时价 < 燃料变动成本时硬发即亏 | 负价时段转深度调峰拿 0.30 补偿，优于硬扛 |
| 风光 | 实时价 < 0 且无可弃电约束时 | 理论上应弃电；受保障收购限制时，靠中长期保价对冲 |
| 售电/大用户 | 负价时段购电成本极低 | 优化用电/储能充放时序，锁定低价窗口 |
| 电厂管理层 | 现货敞口比例决定波动暴露 | 核对辽宁 4.0 合约台账，明确贵厂锁价比例 |

## 十六、价格形成机制：边际出清与出清时序（机理底座）

### 16.1 边际出清（方法论底座）

- 统一出清价 = **最后一个被调度的"边际机组"的报价**，所有中标机组同价结算；价格取决于「最后一千瓦谁报多少」而非平均成本
- 逼出负电价链条：风光零成本优先消纳 → 新能源大发 → 边际机组变刚性火电(贴钱)/新能源负价 → 破零
- **数据实证（价格帽）**：触顶(≈1500) 实时 **16 次**/日前 0 次（晚高峰，顶峰电源冲顶）；触底(≈−100) 实时 **342**/日前 139（双谷风电带）→ 机制在真实运行
  - 要害：触顶只实时有 = 日前预测边际机组 ≠ 实时实际（与「实时比日前更负」对称）
- 串起全部发现：双谷指纹 / 偏差 / 套利 / 电源结构 都挂在它下面
- 诚实边界：机制框架数据完全符合，但看不到具体哪台机组当边际机组
- **辽宁算法口径修正（2026-08-15 实查官方文件补正）**：上文"统一出清价 = 边际机组报价"描述的是**系统边际电价（SMP）**逻辑，即 LMP 中"系统边际成本"这一分量。辽宁现货市场实际采用**节点边际电价（LMP）**机制（《辽宁省电力市场运营规则及配套实施细则（试行4.0版）》第三十一条："现货电能量市场采用分时节点电价机制；发电侧按照所在节点价格进行结算，用电侧按照统一结算点价格进行结算"）。因此严格讲，本文分析的全月均价 / 96 点价格，是各节点 LMP 按上网电量加权后的**统一结算点价**，而非单一系统价；在辽宁电网阻塞较轻的多数时段节点价会趋同于系统价，故"边际机组报价决定价格"的结论仍近似成立，但遇输电阻塞时各节点价会出现分化（= 系统边际成本 ＋ 阻塞分量 ＋ 网损分量）。详见 §17。


### 16.2 出清的完整时序（日前 + 实时）

**（1）日前市场（D-1，本文所抓 `data.before` 预出清参考价即在此阶段产出）**

| 步骤 | 动作 | 输入来源 |
|---|---|---|
| ① 申报 | 发电侧报量报价（单边，用户侧报量不报价，回 §19）；负荷预测曲线作为需求输入（回 §18） | 各市场主体 + 调度机构 |
| ② 新能源预测并入 | 风/光预测出力作为"负负荷"叠加到需求侧 | 新能源预测（§18 双预测之一） |
| ③ 机组组合 SCUC | 决定哪些机开、哪些停，满足**必开必停约束（must-run）**、断面极限功率 | 申报 + 安全约束 |
| ④ 经济调度 SCED | 在 UC 结果上，按报价从低到高"扫描"供给曲线，求解最优出力分配 | SCUC 结果 + 负荷/新能源预测 |
| ⑤ 出清 | 得到每个节点 96 点价格（辽宁 = LMP，见 §17.3 第三十一条） | SCED 解 |

**（2）实时市场（D，本文所抓 `data.realTime` 即此）**

| 步骤 | 动作 |
|---|---|
| ① 滚动出清 | 基于最新负荷/新能源实测，每 15min 滚动 SCED |
| ② 偏差结算 | 日前预测 vs 实时实际的偏差按规则结算（回 §5.5「预测纠偏偏差」定位） |


### 16.3 merit order：出清价如何从供给曲线“跳”出来

第十七节（出清算法）偏算法史，本节补最直观的"出清 → 电价"映射：

```
把所有机组按报价从低到高排成供给曲线：
  新能源（0 或负） → 低煤耗大机组 → 高煤耗小机组 → 气电/稀缺机组
          ↑________________ 负荷曲线从左侧往右"吃" ________________↑
          最后一个被调用、还差一单位满足负荷的机组报价 = 系统边际价（SMP）
```

- 辽宁为 LMP，在 SMP 基础上多出 **阻塞 + 网损** 分量（见 22.3）。
- 本文所挖 **负价 31/31 天、触底 342 次**（§4）：merit order 最左端新能源零成本必发，把高价火电挤到最右；当负荷塌陷（§4 双谷），最后被调用的"边际机组"变成必须开但出力受限的 must-run 火电，它贴钱上网 → 边际价变负。

|---|---|
| §17 算法渊源 | SCUC/SCED 是引擎，本节是引擎如何跑出价格 |
| §18 负荷预测 | 负荷曲线 + 新能源预测是出清的需求侧输入 |

## 十七、电力交易市场出清算法（含辽宁 LMP 实查）

### 17.1 节能调度：算法实践的制度起点（2007）

- 《节能发电调度办法（试行）》（发改能源〔2007〕3523号，国务院批准）：调度顺序按**能耗 + 环保**排——可再生 / 核电 → 低煤耗大机组 → 高煤耗小机组。
- 核心变革：**打破"平均分配发电量"**，谁高效谁多发电。
- 这是第一次用**"优化排序"算法**替代行政摊派，是中国电力优化调度的制度 + 工程起点。


### 17.2 算法内核演化链

```
节能调度（lexicographic 字典序优化：先环保 / 能耗排序）
   ↓  市场化改造
经济调度 ED（给定机组后分负荷，成本最小）
   ↓  加"开哪些机"决策
机组组合 UC（Unit Commitment：哪些机开、哪些停）
   ↓  加电网安全约束
SCUC（安全约束机组组合）＋ SCED（安全约束经济调度）
   ↓  今日现货市场出清引擎
统一出清 → 产出本文价格
```

- **数学内核**：大规模**混合整数线性规划（MILP）**——连续变量（出力）+ 整数变量（开停），由求解器（CPLEX / Gurobi / 国产）计算。
- **目标函数变了，框架没变**：节能调度目标是"能耗最小"；市场化后变成"购电成本最小 / 社会福利最大"（当前多数省份现货以**发电成本最小化**为目标，因用户侧失负荷价值难估），但优化结构和安全约束内核一脉相承。

### 17.3 辽宁具体算法（2026-08-15 实查官方文件）

依据《辽宁省电力市场运营规则及配套实施细则》（试行 4.0 版，辽宁省工信厅 / 国网辽宁 / 东北能监局，2025-12）及政策解读：

- **出清程序**：**第三十条**——日前通过 **SCUC（安全约束机组组合）+ SCED（安全约束经济调度）** 程序出清（决定开机组合与各机组 96 点计划）；实时通过 **SCED** 滚动出清。
- **价格机制**：**第三十一条**——现货采用**分时节点电价机制（LMP）**；**发电侧按所在节点价格结算，用电侧按统一结算点价格结算**。本文分析的全月均价 / 96 点价格，即各节点 LMP 按上网电量加权后的统一结算点价。
- **出清边界约束**（配套细则第三十一条）：断面极限功率、发电机组（群）**必开必停约束**、出力上下限约束等。其中"必开机组（must-run）"——因系统安全、电压支撑、保供热保民生必须并网运行的机组——正是**负价的算法级根源**（机组不能停、又供过于求 → 边际价被算为负）。
- **其他机制**：现货市场力检测采用 **4 种数学模型**缓解；报价限价 −100 ~ 1500 元/MWh（辽宁 4.0），设二级价格限值；日前市场暂停结算（§5.5 已注：本文 `before` 为预出清参考价）。


- **4.0 第三十条**：日前 SCUC+SCED，实时 SCED 滚动出清
- **第三十一条**：分时节点电价 LMP，发电侧节点价、用电侧统一结算点价
- **出清边界**（国网辽宁配套细则）：断面极限功率、**必开必停约束（must-run）**、出力上下限——必开约束正是负价的算法级根源


### 17.4 LMP 三分量拆解

**LMP = 系统能量分量 + 阻塞分量 + 网损分量**

| 分量 | 含义 | 本文对应 |
|---|---|---|
| 系统能量分量 | 全网边际机组报价（merit order 的边际价） | §16 / §17.5 |
| 阻塞分量 | 某断面超限时该节点须调用更贵本地机组，价格被推高；**节点间价差 = 阻塞分量** | 辽宁 LMP 独有，SMP 不含 |
| 网损分量 | 远距离送电的损耗折算 | — |

**关键**：辽宁 §17.3 第三十一条——**发电侧按所在节点 LMP 结算、用电侧按统一结算点价结算**。同一时刻不同节点价格不同，正是 LMP 比 SMP 细之处（也修正了 §16 原纯 SMP 表述）。


### 17.5 算法如何产出本文价格（回链实测）

| 本文现象 | 算法根源 |
|---|---|
| §16 统一出清价 = 边际机组报价 | LMP 中"系统边际成本"分量 = SCED 最优解中负荷平衡约束的影子价格；辽宁阻塞较轻时段节点价趋同于此 |
| 负价 31/31 天、触底 342 次 | **"新能源优先 + must-run 必开约束"** → 新能源必发、火电压最低仍发 → 供过于求 → SCED 算出的边际价变负 |
| 风速 r = −0.553（§5.3） | 算法将"风电大发"作为优先消纳约束，挤掉高价火电 → 价跌，故风越大价越低 |

> 一句话：本文挖的那串负价不是随机的，是算法在"新能源必须优先、火电不能全停"的硬约束下**被算出来的必然结果**。这也修正了 §16 原"统一出清价 = 边际机组报价"的纯 SMP 表述——辽宁实为 LMP，系统边际成本只是其分量之一。


### 17.6 诚实边界

- 本节为机理 + 制度分析，辽宁具体算法已实查官方文件（工信厅 / 国网 / 能监局 2025 版细则）确认；但 SCUC/SCED 求解器参数、必开机组清单、阻塞断面划分等**运行级细节以东北 / 辽宁电力交易中心技术细则红头为准**。
- **nuance**：对中国电力市场语境，算法实践起点是节能调度（2007）；但 ED/UC 算法理论本身在欧美电力系统工程已有数十年历史，非 2007 才出现。准确表述应为——"对中国电力市场，算法实践源头是节能调度；算法理论源头更早"。

## 十八、负荷预测与电价的关系（上游输入层）

> 性质声明：本节为机理 / 制度分析，未抓取逐时负荷数据（用户确认拿不到），"负荷七创新高"为公开报道引用；辽宁负荷预测具体模型 / 精度 / 责任主体以辽宁电网 / 交易中心技术细则红头为准。与第十九、二十节共同构成"上游输入 → 出清算法 → 价格现象"的完整纵深。

### 18.1 负荷预测在市场中的位置

负荷预测 = 估算未来各时段全省 / 全网用电需求，是**日前 / 实时出清的前置输入**，地位在出清算法（§17）之前：

| 层次 | 内容 | 市场用途 |
| --- | --- | --- |
| 系统负荷 | 全网总需求 | 日前出清主曲线 |
| 节点 / 母线负荷 | 各节点需求 | LMP 节点价计算（回 §17 辽宁用 LMP） |
| 净负荷 | 负荷 − 新能源出力 | **真正决定现货价格的瞬时供需差**（§4 核心自变量） |

时间尺度：超短期（15min−4h，实时滚动）/ 短期（次日 96 点，日前出清用）/ 中期（周月，中长期参考）。**在单边市场（§19）中，负荷是预测给定的常数，直接作为需求约束塞进出清算法 SCED**——即"负荷预测误差决定价格"的由来。

### 18.2 与电价的五重关系（回链实测数据）

1. **日前出清的"骨架"主驱动**：负荷曲线决定供需平衡点，与"新能源出力"并列两大价格主驱动。负荷高峰→需求曲线抬高→边际机组进高价段→价高；低谷相反。
2. **负荷预测误差 = 偏差考核根源**（回 §5.5）：日前按**预测负荷**出清，实际≠预测 → 实时纠偏 → 偏差。本文 §5.5 那"41.2% 时点实时<日前"的偏差，根子之一就是负荷预测失准。
3. **温度敏感性 → 尖峰联动**（回触顶 16 次）：制冷 / 采暖负荷是负荷预测最大变量。本文数据里**触顶 16 次（1500 元上沿）** 多与极端温度推高负荷尖峰有关。"负荷↑→电价↑"在温度驱动的尖峰时段**其实成立**，只是被新能源挤出效应在大多数时段覆盖（如 7 月 31 日负荷创新高但价近零）。
4. **净负荷预测 = 负价判断核心**（回 §4）：净负荷 = **负荷预测 − 新能源出力预测**。"双谷负价指纹"本质是双预测叠加——
   - 午间负价 = 负荷午间回落 + 光伏大发（净负荷塌陷）
   - 夜间负价 = 负荷低谷 + 风电大发（净负荷再塌陷）
5. **预测精度 ↔ 价格可预测性**（回 §19）：本文挖的**风速↔实时价 r=−0.553** 在单边下特别"干净"，部分因负荷被当较稳定的预测常数、需求侧干扰小。负荷预测越准，日前 / 实时偏差越小，价格越可预测。

### 18.3 关键机制：双预测误差叠加

电力市场实际跑的是**两个预测同时进 SCED 约束**：

```
负荷预测误差（需求侧）
新能源出力预测误差（供给侧，风 / 光）
        ↓ 都进 SCED 安全约束
        ↓ 任一失准 → 放大实时偏差
        ↓ 二次调频 AGC（§20）实时纠偏的正是这俩总误差
```

即 §5.5 偏差复盘的根子 = 这俩预测误差；§20 的 AGC 忙不忙，也由它俩决定。

### 18.4 与已有成果咬合

| 已有章 | 负荷预测如何嵌 |
| --- | --- |
| §4 负价 / 净负荷 | 净负荷 = 负荷预测 − 新能源预测，双谷负价是双预测叠加 |
| §5.5 偏差 | 负荷预测误差是偏差的一半来源（另一半为新能源预测） |
| §19 / §19 集中单边 | 负荷作为"预测常数"塞进出清，是单边价格形成的关键假设 |
| §20 调频 | 负荷预测误差靠 AGC 实时纠偏 → 预测差则调频需求大 |
| §17 算法 | 负荷预测曲线是 SCED 的必填需求约束（与 must-run 同列） |

### 18.5 辽宁具体情况

- 日前市场（辽宁 4.0 细则）负荷预测由调度 / 交易机构基于历史 + 气象做，是 SCUC/SCED 出清必填输入；

## 十九、市场结构：集中式 vs 分散式 / 单边 vs 双边（两个正交维度）

> 本节为电力市场**制度/机理层**分析，基于公开市场设计文献与国内现货试点规则，未抓取新数据。中国具体规则（各省现货模式、绿电交易细则）以发改委/交易中心红头原文为准（见第七、八节诚实边界）。与第五章价格形成机制（边际出清）、第十四节实操转化互补：前者讲"集中式现货里价格长什么样"，本节讲"为什么长这样、另一种模式会怎样"。

### 19.1 一句话定义

- **集中式（Pool / Centralized）**：所有发电、用电统一向一个市场运营机构报量报价，由它**统一优化出清**，出全省/全网统一价格信号。辽宁当前省级现货即此模式。
- **分散式（Bilateral / Decentralized）**：发电方与用电方**直接双边谈合同**（PPA、协商交易），机构只做安全校核与偏差结算、**不统一出清**；价格由一单一单谈判决定，碎片化。

### 19.2 核心区别对比

| 维度 | 集中式 | 分散式 |
| --- | --- | --- |
| 出清方式 | 统一优化、单一出清价 | 双边协商、多重合约价 |
| 价格信号 | 强、全局、实时（本报告 96 点即它） | 弱、局部、被合约平滑 |
| 负电价 | 容易自然出现（边际机组贴钱上网） | 被 PPA 锁价吸收，物理负价少 |
| 透明度 | 高（全市场价公开） | 低（合约价不公开） |
| 典型代表 | 辽宁/山东/山西现货、美国 PJM、北欧 Nord Pool | 德国双边、绿电 PPA、区块链微网 |
| 中国现状 | 省级现货试点（集中式） | 中长期双边 + 绿电交易 + 分布式隔墙售电（萌芽） |

### 19.3 与电价的关系（四个维度）

1. **价格形成机制**：集中式价 = 最后一个边际机组报价（§16），新能源零成本大发→边际机组变刚性火电贴钱→负电价；分散式价 = 双方谈出来，新能源即便物理该负价，PPA 锁价后结算价仍正，**负价被合约吃掉，转为机会成本负**。
2. **信号传导强度**：集中式下风速↔实时价可达 r=−0.553（§5.3），因现货价实时直接反映供需；分散式下现货仅作偏差结算参考，大部分电量走合约，**波动被缓冲，信号弱得多**。
3. **负电价出现概率**：集中式（高新能源占比）负价成常态信号，逼出调峰/容量对冲（§5.11）；分散式负价多藏在"本可卖更高却被迫低价消纳"的机会成本里，账面不直接破零。
4. **对发电企业收益暴露**：集中式现货下贵厂收益高度暴露统一出清价波动→靠"四轨"（中长期+容量+辅助+现货）托底（§5.10–5.11）；分散式下收益取决于**合约谈判质量**（PPA 锁价），现货只是尾巴，新能源长协 PPA=护城河，火电更靠容量+辅助。

### 19.4 与中国现状及本报告的衔接

- 中国当前非纯集中也非纯分散，而是**「集中式省级现货 + 分散式中长期双边」混合架构**；绿电交易、分布式发电市场化交易（隔墙售电）是向分散式演进的方向。
- 本报告已有成果换个视角即：双谷负价指纹 / 边际出清 / 风速相关（§5.3、§16）全是**集中式现货**特征指纹；"四轨价格"框架（§5.11）本身就是混合体 = 集中式出清的现货价 + 分散式双边的中长期合约 + 容量 + 辅助。

### 19.5 诚实边界

- 本节为制度/机理分析，无新抓取数据；各国/各省市场模式与规则细节以官方红头为准。
- 负价"分散式被合约吸收"为机理推断，非辽宁本地实测；辽宁目前以集中式现货为主，分散式仅在中长期与绿电交易层面存在。

> （上段为集中式 vs 分散式；下段为单边 vs 双边，二者正交，共同决定价格形成路径与参与主体。）


> 本节（单边 vs 双边）与本章前半（第十九章 19.1–19.5 集中式 vs 分散式）是**正交的两个维度**，切勿混淆：
> - 集中式/分散式 = **价格怎么形成**（统一出清 vs 双边谈合同）
> - 单边/双边 = **谁参与报价**（仅发电侧 vs 发电侧＋用户侧都报）
>
> 本对话所分析的辽宁 7 月现货，底层坐标是 **「集中式 ＋ 单边」**——这正是其价格特征（频现负价、信号纯净）的体制根源。

### 19.6 定义

- **单边（发电侧单边竞价）**：只有发电方报量报价，用户侧负荷被当作**预测的固定常数**塞进出清，不参与竞价、无价格弹性。中国当前省级现货试点基本是此模式。
- **双边（双侧报价）**：发电侧**和**用户侧（大用户、售电公司、储能、虚拟电厂）都报价，需求曲线实时参与出清，价格由供需交点决定。

### 19.7 核心区别对比

| 维度 | 单边（仅供给侧报价） | 双边（供需双侧报价） |
|---|---|---|
| 出清价形成 | 预测负荷切供给曲线，取边际机组报价 | 供给曲线 ∩ 需求曲线，交点定价 |
| 需求弹性 | 无（负荷刚性、预测给定） | 有（价高少买、价低多买） |
| 负电价频率/深度 | **高**（盈余无处消纳，只能机组贴钱） | 低（负价时需求增购吸收） |
| 价格尖峰 | 易触顶（供给紧时需求不削减） | 受抑（价高时需求退出） |
| 价格波动 | 大、两端极端 | 被弹性缓冲、相对平滑 |
| 典型代表 | 中国当前省级现货试点 | 美国 PJM/ERCOT、北欧 Nord Pool |

### 19.8 对电价的四点影响（回链本对话数据）

1. **负电价：单边市场的"特产"**——本对话挖出的**实时负价 31/31 天、触底 342 次**，本质就是单边特征：需求侧不参与，新能源大发造成的电力盈余**没人能在低价时增购吸收**，只能靠机组报负价抢上网权。若换双边，部分大用户/储能/虚拟电厂会在负价时段增购，负价次数与深度都会下降。
2. **价格尖峰：单边更易触顶**——数据中**触顶 16 次**（1500 元/MWh 上沿），单边下供给紧张时需求刚性、无需求侧削减，价直接打笼子上沿；双边里高价逼退一部分需求，尖峰通常低于笼子顶。
3. **波动与信号纯度**——挖到的**风速↔实时价 r＝−0.553** 在单边下特别"干净"：价格几乎纯由供给侧博弈＋负荷预测决定，需求侧干扰小，供需传导清晰；双边里需求也在动，信号更"浑"但更稳。
4. **对贵厂（发电企业）的暴露**——单边下现货价完全由供给侧博弈＋**负荷预测误差**决定，预测错了即偏差考核费（呼应 §5.5 偏差定位）；双边下可主动管理需求侧（需求响应、储能、可中断负荷），收益更可控，但多一层"需求侧博弈"复杂度。

### 19.9 与中国现状衔接

当前省级现货试点多为**发电侧单边竞价**（用户侧通常"报量不报价"、按统一出清价结算），这正是辽宁双谷负价频现的体制根源。发改委/能源局推动的**需求响应、峰谷价差、虚拟电厂入市**，本质就是往**双边**过渡——让需求侧变成真正的定价参与者，从根上削负价、压尖峰。

### 19.10 诚实边界

- 本节为制度/机理分析，无新抓取数据。
- "辽宁为单边"属行业通行特征，但**辽宁 4.0 具体用户侧参与规则以交易中心/发改委红头为准**（与 §7/§8 一致）。

## 二十、辅助服务（调频 / 调峰）与电价的关系

> 一次调频、二次调频(AGC)、调峰三者都属于**辅助服务/系统平衡层**，与本文分析的能量现货价是不同层次、但互相咬死：
>
> ```
> 能量市场(现货)  → 决定"发多少电、每度多少钱"   ← 本文主分析层
> 辅助服务市场    → 保证"频率稳、峰谷能平"         ← 一次/二次调频、调峰在此层
> 容量市场        → 保证"关键时刻有装机可用"        ← §5.11 容量电价层
> ```
>
> 三者与电价是"成本—信号"双向咬合：辅助服务成本最终摊进系统、由新能源分摊；而**调峰补偿又反过来让负电价能持续存在**（火电亏能量、赚调峰，才不关机）。

### 20.1 三个概念定位

| 服务 | 提供主体 | 时间尺度 | 触发方式 | 辽宁/东北是否市场化定价 |
|---|---|---|---|---|
| **一次调频** | 机组调速器自动 | 秒级（<15s） | 频率偏差自动响应 | 多为**考核义务**（免补/罚），少数市场补偿 |
| **二次调频(AGC)** | AGC 机组 | 分钟级 | 调度下指令跟负荷 | 是，**独立调频市场**（里程价+容量价） |
| **调峰(深度调峰)** | 火电等可滑机组 | 小时级 | 负荷低谷/新能源大发 | 是，**调峰辅助服务市场**（按低于阈值电量补偿） |

### 20.2 各自与电价的关系

- **一次调频 vs 电价——隐性成本**：强制义务＋考核为主，通常不直接给钱，是发电侧的"免费义务"；不改变现货出清价，但要求机组留**旋转备用裕度(headroom)**→ 牺牲能量市场满发收益（机会成本）。对火电：提供一次调频就得保持可调空间，没法在现货高价时顶满 → 间接压低火电现货段收益（呼应 §14.2 火电微利）。
- **二次调频(AGC) vs 电价——独立现金轨**：有独立调频市场，自己的价格（里程单价/容量价），是"辅助服务"那轨的现金来源；新能源占比越高 → 波动越大 → 调频需求↑ → **调频价↑**，是火电/储能的额外收入。代价：AGC 机组随时跟调度指令，放弃部分能量市场灵活性 → 能量收益可能牺牲（双市场博弈）。回链：本对话挖的**双谷负价**（午间光伏、夜间风电）两个剧变段，恰好是 AGC 最忙的时候 → 现货负着、调频市场却在高价收容量，构成火电"能量亏、辅助赚"的组合（呼应 §14.3 火电三层缓冲）。
- **调峰(尤其深度调峰) vs 电价——最直接的一座桥**：这是把"负电价"和"火电为何不关机"焊死在一起的机制——火电在负价时段压到低负荷继续发，**亏在能量价、赚在深度调峰补偿**（辽宁约 0.30 元/kWh，需核红头，见 §5.11）。**调峰市场 与 现货市场是替代关系**：现货成熟后，负价本身就是调峰信号，理论上不需另设调峰补偿；中国处于过渡期——两者并存，出现"负价＋调峰补偿"双重结算。新能源是调峰成本的承担方：东北/辽宁要求新能源分摊调峰费或配储，这笔钱最终变成火电深度调峰的收入 → 形成"**新能源补贴火电调峰**"闭环。

### 20.3 与已有成果的咬合

- **接 §4 负价成因**：新能源大发 → 现货负价（31/31 天）→ 火电靠**深度调峰补偿＋中长期锁价＋容量电价**三托底才不关机（§14.2＋§14.3）→ 调峰/调频成本由新能源分摊 → 新能源度电成本上升，把"负价为什么能存在"讲透。
- **接 §5.11 辅助/容量**：一次调频≈考核义务（几乎无价）、二次调频=辅助服务定价轨、调峰=辅助服务定价轨（正被现货吸收），三者正是"四轨"框架里**辅助服务那一轨**的内部拆解。
- **接 §19 单边/双边**：这仨全在**供给侧**（发电侧义务/市场），所以在本文"集中式＋单边"坐标下，平衡成本全压发电侧、需求侧不参与 → 进一步解释为什么现货波动大、负价频；若走向双边，部分调峰压力可由需求侧响应分担。

> 配套机理图示：`../可视化图表/辽宁省电价市场机制机理图.html`（2×2 市场结构矩阵 ＋ 能量/辅助/容量三层价格层次）。

### 20.4 诚实边界

- 本节为机理分析，无新抓取数据。
- 辽宁/东北具体补偿价（0.30 元/kWh 深度调峰、调频里程价）、一次调频是否纯考核、新能源分摊比例，**以东北区域/辽宁电网辅助服务细则红头为准**（同 §7/§8）。

## 二十一、绿电（绿色电力交易与绿证）与电价的关系

> 此前的"四轨价格"（现货 / 中长期 / 辅助 / 容量）全部是**电能价值**维度，漏了绿电独一档的**环境价值（绿证）**——这是框架级缺口。本补充章将其补齐为"五维"。

### 21.1 绿电是什么（两个东西）

- **绿色电力交易（绿电交易）**：2021 年 9 月全国启动，由北京 / 广州电力交易中心组织，以"证电合一"为主（电与绿证绑定交易）；买的是"带环保身份的电"。
- **绿色电力证书（GEC，绿证）**：1 个绿证 = 1000 kWh 可再生能源电量，是**环境价值的凭证**，可单独交易、可国际接轨（RE100）；绿证价格是电能价之外的"绿色环境溢价"。

**绿电价格 = 电能价格（随行情 / 合同）＋ 绿色环境溢价（绿证价）** ← 多出来的"第五维"。

### 21.2 绿电与电价的四重关系

- **价格结构多了一维**：把"四轨"升级为**"五维"**——现货 + 中长期 + 辅助 + 容量 + **环境价值（绿证）**。
- **对新能源 = 对冲现货负价的护城河**：本文挖的实时负价 31/31 天、触底 342 次，新能源在那些时段现货价可能为负或近零；但绿电合约（年度 / 月度双边）锁了**溢价**，让新能源回收环境价值、不至于"贱卖到负"。这解释了为什么新能源愿意在负价时段继续发（不止硬扛，还有绿证现金流）。
- **对现货价：不直接减负价，但改变新能源报价行为**：绿电合约锁价后，新能源在现货市场更"不在乎"低价 → 可能更激进报低价抢上网权 → 一定程度上压低现货边际价。机理上两头都有（溢价兜底 vs 加剧低价竞争），此定性结论须核真实申报数据。
- **消纳责任权重：制度性需求撑起绿证溢价**：国家强制各省 / 重点用户购买一定比例绿电 → 创造刚性需求 → 绿证才"贵得有理"，是绿电溢价能存在的制度根基。

### 21.3 与已有成果的咬合

| 已有章 | 绿电如何嵌入 |
|---|---|
| §5.10 中长期 | 绿电交易本质就是**中长期双边合约**的一种（年度 / 月度） |
| §19 集中 / 分散 | 绿电交易 = 典型**分散式双边 PPA**（与辽宁集中式现货并列） |
| §19 单边 / 双边 | 绿电 = **双边**（用户侧主动买绿电、参与定价） |
| §20 调峰 | 新能源分摊调峰费 / 配储 → 绿证溢价部分覆盖该成本 → **"环境溢价 → 覆盖消纳成本 → 新能源可持续"闭环** |

### 21.4 诚实边界

- 本节为机理分析，未抓新数据。
- 绿电交易具体细则、**绿证当前价格**（近年从几十到几百元 / 张波动大，本文只给区间不给定点）、消纳责任权重具体值、绿电合约电量占比、辽宁新能源企业实际绿电签约比例——**以北京 / 广州电力交易中心、发改委、能源局红头为准**（同 §7/§8）。

## 二十二、市场规则与考核层：预测考核、计划考核、AGC 调节考核、批零传导

> 本节补齐文档"价格结构层"之外的**最后一公里**：前面各章（§5.10 中长期 / §5.11 辅助容量 / §21 绿电 / §14.2 机组画像）算的 +5.9 / −0.30 / 负价 31 天都是**理论价格层**；而本节四个机制是**"价格如何变成发电企业账户实际到账"的规则与考核层**——考核费、偏差结算、批零传导全在此扣减。

### 22.1 新能源功率预测考核

- **机理**：新能源场站须上报次日 96 点功率预测（日前），调度据以做平衡。预测准确率 / 合格率不达标 → **"两个细则"新能源功率预测考核费**。常见口径：准确率 = 1 − ∑|预测−实际| / ∑实际 的某种积分；合格率 = 偏差在阈值内时段占比。
- **与负价咬合（回 §4 / §18）**：预测高估 → 多发电量挤进已过剩现货 → 加剧负价；预测失准 → 调度为安全压出力 → **弃风弃光**。故"预测准不准"直接决定新能源自身亏损幅度。
- **位置**：即 §18.3「双预测误差叠加」中**新能源侧误差的制度化惩罚**——§18 只讲误差机理，本节讲其考核落地。

### 22.2 发电计划考核曲线

- **机理**：出清给每机组的"中标曲线"（§16.2 步骤⑤）即发电计划；实际出力须跟踪该曲线。偏离计划 / 非计划停运 → 考核（"两个细则"发电计划执行偏差考核）。
- **与出清/偏差咬合（回 §16 + §5.5）**：这正是"日前出清 vs 实时实际"偏差的**考核落地**；对火电，深度调峰压负荷跟踪曲线（§20）跟踪不好亦罚。
- **位置**：把 §5.5「41.2% 时点实时<日前」的偏差，从"预测纠偏偏差"进一步落到"计划执行偏差考核费"。

### 22.3 AGC 调节性能考核（补完 §20）

- §20 讲了"二次调频(AGC)是独立现金轨（里程价 + 容量价）"，本节补其**调节性能考核**维度——决定补偿能拿多少：
- **综合性能 Kp = K1 × K2 × K3**：
  - **K1 调节速率**：单位时间出力变化率（MW/min）
  - **K2 调节精度**：实际出力与指令的跟踪误差
  - **K3 响应时间**：从指令下发到开始动作的延迟
- **机制**：性能不达标 → 补偿打折甚至考核；达标 → 拿全额里程 / 容量补偿。即 §20 讲"AGC 怎么赚钱"，本节讲"**考核决定能拿多少**"。
- **回链 §18.3**：负荷 / 新能源预测误差大 → AGC 越忙 → 调节性能考核压力越大。
