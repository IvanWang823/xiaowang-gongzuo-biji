护栏红线（最高优先级）
① 口径铁律：指数即期（SCFI 约千点级）与全包价（基本运费+四类附加费，USD/TEU）区间不同，禁混用；汇总须拆即期/全包两行、禁跨口径直接 SUM。
② 数据缺失不编造：缺逐日/逐周数据明说，生成「待补充字段清单」，绝不幻觉补全。
③ 归因逻辑须可追溯：运价=f(供−需−利用率)×弹性，结论回溯源字段+公式，误算可秒定位。
④ 不预测具体买卖/不荐具体交易：客观研判区间与驱动，订舱/采购决策留给人。
⑤ 模式动态切换：用户未指定→纯客观；明确要求→加优化建议，结束后复位。
🛡️
质量保险栓
① 数据时间戳：左侧每个输入原料框已含「📅 数据日期/周期」占位符，喂数时逐项填实，禁跨期混算（今日 SCFI + 上月出口量 = 假精确）。
② 重复数据检测：同指标多源→以权威源（上海航交所 SCFI/CCFI）为准，不自动累计，先确认。
③ 计算过程可追溯：核心结论（运价弹性=利用率区间映射）须回溯源字段+公式。
④ 结论置信度评级：数据完整度/口径一致性/因子覆盖 + 整体评级，缺项不装「全知」。
02 研究框架 指数 · 因子 · 成本结构 · 审单 · 方法

分析步骤（① 锁定对象 → ② 搭建数据池 → ③ 拆解因子 → ④ 输出决策）已在第一部分「工作流信息架构图」完整呈现，此处不再另画流程图，聚焦各步骤对应的数据与方法卡片。

一、运价指数体系 别盯错指标

不同指数口径、频率、覆盖范围都不一样，混用会得出相反结论。集装箱看 SCFI/CCFI/FBX，大宗商品（煤炭/铁矿）看 BDI。

维度指数频率口径 / 代表意义主要出处
即期SCFI 上海出口集装箱运价指数周中国出口即期风向标，最常用上海航运交易所
综合CCFI 中国出口集装箱运价指数周即期+合约综合，波动比 SCFI 平滑上海航运交易所
即期NCFI 宁波出口集装箱运价指数周华东另一出口锚宁波航运交易所
日频FBX Freightos Baltic Index日高频，适合盯短期异动（含平台偏差）Freightos+Baltic
日频WCI World Container Index周全球 8 条主干航线即期基准Drewry
干散货BDI 波罗的海干散货指数日非集装箱，看大宗商品海运成本波罗的海交易所
期货SCFI 欧线期货交易可对冲/投机的定价上期所(INE)

最该盯的两条：SCFI（官方周频，权威）做趋势/月度复盘；FBX（商业日频）做日度异动监控。交叉验证优先信官方周频。

二、核心影响因素拆解 分析的主轴

运价本质是供需定价，但被成本与事件剧烈扰动。建议按"供需 / 成本 / 事件"三层拆，核价再叠加审单。

2.1 供需层 决定方向

维度看什么数据线索
运力供给全球集装箱船队运力（万 TEU）、新船交付、闲置/拆解率、航速（减速=隐性减运力）Clarksons、Alphaliner
货量需求中国出口金额/集装箱吞吐量、欧美进口订单（PMI 新出口订单）、零售商库存海关月报、港口吞吐量
舱位利用率85–90% 维稳，>95% 陡增，<85% 踩踏跌船公司/研究机构周报

运价弹性经验值（行业硬锚点）：利用率 85–90% 维稳；突破 95% 呈非线性陡增——需求每涨 1%，运价往往涨 5%–10%（欧线/美线经验法则）；跌破 85% 运力过剩易踩踏跌。做三情景时把利用率区间映射到弹性，而非线性外推。

2.2 成本层 决定地板 —— 按四类费用结构拆

类别费用项触发 / 挂钩
① 基本运费按箱型/计费标准计收的基础运费SCFI 即期底价、合约 FAK 价
② 核心附加费BAF 燃油 / CAF 货币 / PSS 旺季 / GRI 宣涨 / CIC 不平衡挂钩 VLSFO 油价 · 汇率 · 季节 · 船司宣涨
③ 港口操作类THC(OTHC/DTHC) / DOC / Seal / AMS·ENS·AFR 申报 / 港杂起运港+目的港两端，相对刚性
④ 特定附加费EU ETS 碳税 / 红海绕行 / 巴拿马 / 拥堵 / 战争险 / 冰冻事件驱动，运价尖峰放大器

2.3 事件 / 政策层 制造尖峰

红海危机（2023 末起，绕行好望角 → 运距 +30%、运力吸收、运价暴涨）· 地缘/制裁 · 罢工（ILWU/德英）· 政策（关税预期/退税）· 疫情黑天鹅。事件冲击通常先在 SCFI 即期体现（1–2 周），再向合约价传导（季度谈约）。

2.4 审单四大关键点 核价 / 对账必查

#关键点查什么 / 防什么
1计费标准核对W/M 择大 / FAK；FCL 还是 LCL；避免错算箱型导致底价虚高
2附加费完整 & 防重复比对四类清单；港口操作类与特定附加费有无同一费收两次（THC 与 local 重叠）
3币种 / 汇率 / CAF币种、结算汇率基准日、CAF 是否已含；避免汇率吃掉利润
4约价适用 & 免费箱使期合约价是否适用本票；Demurrage & Detention 免费天数、超期费率

说明：上表四点为本框架推荐的通用审单清单。若你那边有固定口径，告诉我具体四条，直接替换。

2.5 合约价（长约）vs 即期价（Spot）分析权重

维度即期价 Spot合约价（长约/BCA）
决定什么边际波动（当下供需+事件）船司利润底线 / 大直客成本锚
频率/敏感周~日频，极敏感季/年谈定，刚性
谁用临时订舱、短线决策电力进口煤、大型出口商年度预算

2.6 与本职联动：BDI → 煤炭到岸价 打通散货逻辑

散货走 BDI 体系，与集装箱两套逻辑，但服务于你本职成本测算：

煤炭到岸价（CIF） = FOB 离岸价 + 海运费 + 港杂/保险
海运费（散货） = BDI 对应分船型运费率 × 吨海里（澳煤高卡→海岬型 BCI；印尼/南美中卡→巴拿马型 BPI）

应用：用《2026 上半年动力煤价格复盘》"澳洲 Q5500 到岸约 965 元/吨"反拆——FOB 占多少、海运费（BDI+VLSFO 即 BAF）占多少、附加费占多少 → 精确判断电厂买内贸还是买进口。集装箱与散货两套口径勿混用。

四、怎么分析 方法论

4.1 趋势与周期

同比（YoY）剔季节看周期位置 · 环比（WoW）看边际方向 · 分位数（历史第几%）高位警惕回落、低位看拐点 · 季节性（春节前抢出口、Q3 圣诞补货→旺季叠加 PSS）。

4.2 相关性 / 归因

运价 vs 油价（弱相关）· vs 中国出口金额（强相关，需求驱动）· vs 舱位利用率（最强相关）· 红海绕行后 vs 有效运力。方法：用 Python（pandas）做相关系数矩阵 + 滚动相关，找当阶段主驱动。

4.3 情景与预测

基准/乐观/悲观三情景：给定运力增速、货量增速、事件是否缓和；运价弹性测算（利用率每变动 X%，运价变动 Y%）；周频更新，月频复盘。

4.4 可视化看板（建议）

① 各航线 SCFI 走势（多线折线，按年着色） ② 运价历史分位热力图（航线×时间） ③ 运价 vs 油价/出口金额 双轴图 ④ 事件标记时间轴（红海、罢工、关税）。

五、标准实操流程 从数据到结论

  1. 定目标 → 看趋势？监控异动？测算成本？选对应指数
  2. 拉数据 → SCFI 周频历史 + FBX 日频 + 出口/油价辅助
  3. 清洗 → 统一币种/单位，补齐缺失周，标注事件日
  4. 描述 → 同比/环比/分位，定位当前周期位置
  5. 归因 → 相关性分析，识别当阶段主驱动（需求?运力?事件?）
  6. 情景 → 三情景定价，给出区间而非单点
  7. 出图/出报告 → 看板 + 一段话结论

六、常见坑 务必避开

#坑
1把 SCFI 即期当船公司真实盈利（漏算附加费、合约占比）
2单看 BDI 判断集装箱运价（BDI 是干散货，逻辑不同）
3用 FBX 日频拐点下长期结论（噪声大，需周频确认）
4忽略基期：指数点位跨年不可直接比绝对值，要比涨跌幅/分位
5事件驱动暴涨后线性外推（红海类冲击有"缓和即回落"特征）
6只核基本运费、漏掉附加费重复计收（同一费在港口操作类与特定附加费里被收两次）→ 见 §2.4 审单四大关键点

八、理论依据 · 学术支撑 方法论底层

本节为框架的方法论底层。可验证的指数、机构、方法来源汇总见同目录 ../_元信息/论文辅助.md。

① 指数体系权威口径：SCFI/CCFI/NCFI 由上海航运交易所发布、BDI 由 Baltic Exchange 发布，是事实层数据源；分析须直接对接官方口径，不自造指数。

② 运价形成机制：供需（运力/货量/舱位利用率）+ 成本（BAF/CAF/ETS）+ 事件（红海绕行）三重驱动；舱位利用率破 95% 呈非线性陡增（行业经验锚点）。

③ 事件冲击建模：红海绕行（2023.12 起）吸收全球 ~5%–10% 有效运力，复航则释放 ~6% 运力、运价 3 周内回落 15%–25%（Alphaliner 统计）；归因用协整/VAR/事件研究法。
