🧠 核心认知
你负责提需求，AI负责写代码（产品经理+开发实习生分工模型）
🧑‍💼
你的工作
  • ✅ 定义页面UI样式与布局
  • ✅ 梳理页面交互操作逻辑
  • ✅ 输出标准化前端需求文档
🤖
AI的工作
  • ✅ 将需求转化为HTML/CSS/JS代码
  • ✅ 根据文档自动对接后端接口
  • ✅ 输出贴合业务流程的可运行代码
⭐ 无需掌握编程语法，但必须学会“梳理需求文档”与“校验AI输出代码”
🎨 Prompt第一式：定义页面UI样式
（给“长相”）· 库存管理后台统一视觉规范
❌ 错误示范（模糊描述，AI输出效果不可控）
“做个好看的后台”
✅ 正确示范（精准参数，AI输出符合预期）
“左侧固定导航 + 顶部面包屑，
主色 #1677ff，表格行高亮，按钮圆角8px”
📌 统一设计标准 主色：#1677ff；字体：Inter；基础间距：16px栅格；列表默认每页展示20条数据
🧩 Prompt第二式：拆分页面模块
（给“零件”）· 库存系统8大核心页面路由清单
📋 路由清单（可直接复制发给AI）
/login 登录页
/dashboard 数据看板
/inventory 库存列表
/inbound 入库管理
/outbound 出库管理
/products 商品管理
/warehouse 仓库与库位管理
/alerts 库存预警
💬 操作建议：直接复制清单发给AI，并补充指令：「根据以上8个页面，生成配套Vue路由配置代码」
⚡ Prompt第三式：定义交互流程
（给“动作”）· 库存系统完整入库业务流程
📦 入库流程（描述给AI）
1. 仓库员点击「新建入库单」
2. 选择SKU（商品编码）+ 数量 + 库位 → 提交 → 状态变为 PENDING（待审核）
3. 审核人审批 → 通过后状态变为 APPROVED（已审核） → 库存自动增加对应商品库存数量（quantity）
📌 描述完整链路：点击新建单据 → 填写表单提交 → 管理员审核 → 审核通过自动增加库存
🧰 Prompt第四式：指定项目技术栈
（给“工具包”）· 库存管理系统技术选型标准
框架 Vue 3 + Vite 构建工具，用于项目开发与打包
UI库 Element Plus 组件库，提供表格、表单、弹窗等UI组件
状态管理 Pinia，用于管理用户登录状态与库存数据
网络请求 Axios HTTP客户端，统一拦截器处理Token认证
⭐ 复制指令给AI：基于Vue3 + Vite、Element Plus、Pinia、Axios技术栈开发前端页面
📄 核心技巧：交付完整前端需求文档
标准化文档交付AI，大幅提升代码可用性
📊 核心数据模型(数据库文档)
商品：skuId（商品编码），name（名称），category（分类），price（单价）
库存：skuId（商品编码），quantity（当前数量），lockedQty（锁定库存，已被订单锁定的数量）
出入库单：orderNo（单号），type（类型），status（状态）
🔗 API 接口约定(接口文档)
GET /api/inventory （获取库存列表）
POST /api/inbound （新建入库单）
POST /api/outbound （新建出库单）
统一响应格式：{ code（状态码），data（数据），message（提示信息） }
📋 完整文档包含7大模块：项目概述 / 技术栈 / 页面路由 / 数据模型 / 交互流程 / API接口 / UI规范
🎯 交付全套标准化文档后，代码逻辑准确率可从40%提升至90%
🔥 终极高效用法：完整文档 + 单行需求指令
上传项目文件+全套文档，一句指令完成迭代
// 你只需要发送这一句指令： “根据我们提供的开发文档，在 /inventory（库存列表）页面增加一列 ‘库位编号’，
并且同步更新导出Excel功能，包含该字段。” // AI 将自动完成以下工作： ✅ 定位到 inventory 对应的 Vue 页面文件 ✅ 在表格中插入“库位编号”列 ✅ 更新导出逻辑，确保新字段被包含 ✅ 匹配后端 API 中的 warehouseId（库位ID）字段进行数据对接
💡 无需记忆复杂代码文件路径 —— AI通读完整文档后，可自主识别项目目录结构。
⚠️ 风险警示：AI生成代码存在3类安全隐患
AI优先实现功能，极易忽略项目安全与可用性问题
💣 密码硬编码 —— AI可能将账号密码直接写在代码中，浏览器F12即可查看源码导致泄露
💣 XSS跨站脚本攻击风险 —— AI习惯使用 innerHTML 渲染动态内容，攻击者可注入恶意脚本窃取用户信息
💣 接口地址虚构 —— AI会自行编造不存在的后端接口地址（如“/api/delete”），上线后功能全部报错
🛡️ AI生成代码禁止直接部署上线，必须人工校验修复后才能投入使用
🔍 代码校验三步法（避坑自查）
无需读懂源码，3个简易操作完成安全校验
👀
第一步：检查地址栏
确认浏览器地址显示为 http://localhost（本地测试环境），方可安全预览
🔎
第二步：搜索敏感关键词
按F12打开开发者工具，搜索 password 或 key 等关键词，若发现明文密码或密钥，立即删除并改用环境变量配置
🧪
第三步：逐一点击测试全部按钮
依次点击页面所有可交互元素，若控制台出现红色报错信息，将完整的报错内容复制粘贴回AI对话框，要求AI修复后重新验证
🧘
