一、先说这是个什么东西

定位

ai-support-bot 是一个跑在你自己电脑上的轻量智能客服： 后端用 FastAPI，前端是原生 HTML 页面，对接 ima 知识库 OpenAPI 做检索， 同时内置本地话术库兜底，支持转人工降级，还能收集用户反馈。

三件事逼出来的：

  • 重复咨询太多 —— 退货、运费、发货时间天天有人问，纯人工答太浪费。
  • ima 知识库硬伤 —— 只索引笔记标题、不索引正文，问得细就检索不到。
  • 需要离线和降级能力 —— 网络/接口挂了不能整个崩，得有兜底、能转人工。
目标很明确： 本地能跑 · 不依赖重型框架 · 凭证安全不入库 · 能稳定降级。
🛠️

三、从 0 到 1 的六个里程碑

里程碑
  • ① 安装与配置： 安装并审计 ima 技能，API Key / Client ID 写进 config.md，用 .gitignore 彻底忽略；重写 main.py 对接真实 OpenAPI；新增 VS Code launch.json 解决调试问题。
  • ② 前端首页 + 三级兜底： 后端加 GET / 返回 index.html；瑞士极简风 16:9 宽屏；兜底逻辑：喊「人工」→转人工，知识库无结果→转人工，接口异常→系统维护中。
  • ③ 本地话术优先： 用 _gen_faq.py 从 ima 笔记拉取正文，切出 20 条 Q&A 落进 faq.json；自写模糊匹配（Jaccard 相似度），命中即答、不走网络。
  • ④ 砍掉语音输入： Web Speech API 国内网络下识别服务不可达，整体移除，改纯文字输入，保稳定。
  • ⑤ 反馈闭环： 每条回答下挂 👍/👎，点完写 feedback.csv；知识库答不上来的问题自动落盘（状态「待补库」）；存储从 openpyxl 改成标准库 csv。
  • ⑥ git 与文档收尾： git init，.gitignore 已忽略 config.md / feedback.csv / __pycache__；写完整 README，流程、字段、已知问题、git 规范全记下来。
