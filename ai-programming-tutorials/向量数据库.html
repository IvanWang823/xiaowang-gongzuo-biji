第一章

两种数据库，两个数据世界

为什么传统数据库管不了你的手机照片？

传统数据库

数据来自管理系统：表格规整，精确记录。查询靠 SQL 精确匹配。

向量数据库

数据来自日常文件：非结构化，语义丰富。查询靠相似度匹配。

第二章

把"感觉"变成数字

Embedding Model —— 语义聚合/压缩模型

▲ 图片经过 Embedding Model 被压缩为一串代表"猫感"的数字向量

语义越相近的内容，向量在数学空间中的距离就越近。猫图和猫文的向量很近，和狗图则很远——这就是机器"理解"语义的基础。

第五章

ima 如何工作？

五步实现"问一句就回答"

  • 1上传文档：将 Word、PDF、网页拖入 ima。
  • 2向量化：后台调用 Embedding Model 生成语义指纹。
  • 3存储索引：向量存入底层向量数据库。
  • 4提问检索：用户问题也被向量化，ANN 搜索相关段落。
  • 5生成回答：大模型基于召回内容总结答案。
